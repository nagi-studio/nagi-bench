# 验证记录

## 可重复执行

```bash
npm run check
npm run build
npm run test:browser
```

`test:browser` 在 5174 端口启动 Vite 并打开 `/tests/verify.html`。如果已有开发服务器，也可直接访问 `http://localhost:5173/tests/verify.html`。

测试页使用项目自身的 three.js、地图、寻路与引擎代码，无新增测试框架或依赖。为了快速验证，测试会访问引擎内部方法并推进固定步长，不等待真实回合时间；不会修改正常游戏的运行入口。固定随机种子用于重复验证。

### 真实 UI 操作验证

另外用 Chromium 操作实际页面验证了：

1. 部署页加载、场景绘制、阵营与配置控件。
2. 点击部署后取得 Pointer Lock，创建 10 名角色。
3. WASD 移动、左键开火扣弹。
4. 选择 AWP 后右键进入瞄准镜：真实 FOV 为 24°，2D 遮罩存在，小地图保持可见。
5. Esc 暂停后角色/AI/计时冻结；点击“继续行动”恢复。
6. B 打开军械库，选择 AK-47，返回战场后库存更新。
7. 1280 × 720 和 1440 × 900 桌面界面；390 px 宽窗口无横向页面溢出。
8. 控制台没有未捕获异常，资源没有 404。

浏览器自动化仅是开发时使用的外部验证工具；项目运行和自带测试页均不依赖 Playwright 或其他游戏/物理/寻路库。

## 验证边界

- 测试不能替代各显卡、浏览器的长期实机压测。软件 WebGL 渲染的帧率不代表硬件 GPU 性能，固定模拟频率为 60 Hz 不等于承诺所有设备 60 FPS。
- 音效合成节点在真实音频上下文中启动，没有播放外部音频文件；自动化未对主观音色做听感评分。
- 这是 Dust II 核心拓扑的压缩低多边形实现，地形高差做了简化，不宣称与官方地图尺寸或战术平衡完全一致。
