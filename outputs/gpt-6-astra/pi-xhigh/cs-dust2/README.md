# DUSTLINE / Tactical Protocol

基于 **Vite + React 18 + TypeScript + three.js** 的浏览器第一人称 5v5 爆破战原型。

**没有外部模型、图片、字体或音频资源。** 建筑、箱子、门、人物、枪械、第一人称手臂均由代码生成；墙面噪声、区域标识由 Canvas 在内存中绘制；全部音效由 Web Audio 合成。运行时依赖仅为 `three`、`react`、`react-dom`。

## 启动

需要 Node.js 20.19+ 或 22.12+，推荐使用最新 LTS。

```bash
npm install
npm run dev
```

打开终端显示的地址，默认 **http://localhost:5173**。选择阵营和开局配置，点击 **进入战场**。建议使用桌面版 Chrome / Edge / Firefox，开启硬件加速；需要键盘和鼠标。

```bash
npm run check    # TypeScript 严格类型检查
npm run build    # 类型检查并生成 dist/
npm run preview # 预览生产构建
npm run test:browser # 在浏览器打开无额外依赖的回归测试页
```

浏览器要求用户手势才能开启音频和鼠标锁定。如果首次锁定被拒绝，在暂停面板点击“继续行动”。不要直接用 `file://` 打开 `index.html`。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 / 转向 | WASD / 鼠标 |
| 开火 / 挥刀 | 左键；步枪支持按住连射，手枪/AWP/刀逐次点击 |
| 跳跃 / 静步 | Space / 左 Shift |
| 换弹 | R；空弹匣再次开火也会尝试换弹 |
| 主武器 / 副武器 / 刀 | 1 / 2 / 3 |
| AWP 开镜 | 右键，再次右键关闭；射击、换弹、换武器会退镜 |
| 安放 / 拆除 C4 | 在目标区域静止，持续按住 E |
| 接管存活队友 | 阵亡后 V，或 Space |
| 战绩表 | 按住 Tab |
| 军械库 | B，仅全装回合前 20 秒且位于己方出生区域 |
| 暂停 / 释放光标 | Esc；切出浏览器也会暂停 |

暂停时，物理、AI、回合计时和 C4 倒计时一起冻结。设置面板可调音量、鼠标灵敏度。

## 对局规则

- 场上始终以 **5 T 对 5 CT** 开局：1 名玩家、4 名 AI 队友、5 名 AI 敌人。
- 可以选择 T 或 CT。第一局可选经典手枪局：所有 T 携带 Glock、所有 CT 携带 USP，无主武器、无护甲，均有刀。
- 手枪局后的回合改为全装配置。全装出生时 100 HP / 100 护甲；这是即时练习模式，不实现经济、购买价格或跨回合装备保留。
- 回合时长 115 秒。未安放 C4 时，超时判 CT 胜。
- 每回合由一名 T 携带 C4，玩家选择 T 时首位持包者就是玩家。持包者阵亡会掉包，存活 T 靠近自动拾取。
- A/B 圆形目标区内按住 E **3.2 秒**安放；安放后 **40 秒**爆炸。CT 靠近 C4，按住 E **5 秒**完成拆除（本原型统一使用拆包器时长）。
- 安放后即使 T 全灭，回合仍继续；CT 必须拆包。CT 全灭或 C4 爆炸为 T 胜；未安放时 T 全灭，或成功拆包，为 CT 胜。
- 回合结束展示胜负，7 秒后自动开启下一回合，累计双方比分。没有固定回合上限。
- 玩家阵亡后自动跟随存活队友观察，按 V 可接管，不会凭空复活或增加人数。
- 关闭友军伤害；队友身体仍会挡住子弹。

## 武器与命中

所有武器参数集中在 `src/game/weapons.ts`：

| 武器 | 基础伤害 | 弹匣 | 单次射击间隔 | 特点 |
| --- | ---: | ---: | ---: | --- |
| AK-47 | 39 | 30 | 0.105 s | 高伤害，明显视角上扬、横向抖动和持续扩散 |
| M4A4 | 32 | 30 | 0.085 s | 更高射速，较低后坐与扩散 |
| AWP | 150 | 5 | 1.55 s | 有甲胸部一击致命；开镜改变真实 FOV，并叠加圆形瞄准镜遮罩 |
| Glock-18 | 21 | 20 | 0.18 s | T 默认手枪 |
| USP-S | 25 | 12 | 0.22 s | CT 默认手枪 |
| Desert Eagle | 30 | 7 | 0.32 s | 介于普通手枪与步枪之间，弹匣小、后坐大 |
| 刀 | 55 | — | 0.55 s | 2.3 m 近战判定，持刀移速更高 |

射线先与地图实体、角色各部位网格求交，取最近交点，不能隔墙命中。命中系数：**头 2.0、胸 1.0、腹 1.1、臂 0.65、腿 0.70**。非腿部命中可由护甲吸收 32% 伤害，护甲吸收量会消耗护甲值；护甲不足时只吸收剩余护甲量。手枪局没有头盔或额外护甲。

## 地图

地图完整包含并连通：

```text
                        CT 出生点
                   /        |        \
               B 门        中门       A 坡道
                |           |             |
               B 点       中路 —— 猫道 —— A 点
                |           |             |
             上 B 洞 —— 下 B 洞          A 大
                |           |             |
             B 洞外场       T 坡道     A 大门 / 坑位
                  \         |         /
                         T 出生点
```

地图是 **Dust II 核心走位拓扑的程序化压缩重建**，不是官方 BSP 或逐尺寸复刻：保留区域、双点、分支绕行、箱体掩体和可通行双扇门；地面高度进行了简化，猫道没有还原官方完整坡度与台阶。建筑外观采用低多边形沙漠城镇风格。

- 生成连续地面网格，只在房间并集的外边界构造墙，确保连通口不会被隐藏墙封住。
- 墙、箱、门板、门柱、车辆、隧道顶棚均有碰撞。门的中央开口可通行，两侧门板不能穿过。
- 小地图对应同一份地图数据，显示自己、队友、被小队最近目视的敌人、C4 及 A/B 标记；敌人目视信息保留 2.5 秒。

## AI 与架构

```text
src/
├── main.tsx                 React 挂载
├── App.tsx                  部署、HUD、暂停、军械库、设置、战绩表
├── styles.css               响应式战术界面
├── components/
│   ├── Icons.tsx            内联 SVG 图标与枪械轮廓
│   └── Minimap.tsx          Canvas 小地图
└── game/
    ├── types.ts             角色、库存、命中区、回合与 UI 快照类型
    ├── engine.ts            权威状态、60 Hz 固定物理步、AI、回合/C4、输入、渲染生命周期
    ├── map.ts               地图区域、程序化场景、AABB 碰撞、静态几何合批
    ├── navigation.ts        自研最小堆 A*、可通行边预计算、路径平滑
    ├── models.ts            分段类人角色、持枪姿态、武器、手臂、C4 与资源释放
    ├── weapons.ts           可扩展武器数据与库存工厂
    └── audio.ts             噪声/振荡器/滤波器合成、音量与立体声定位
```

### 数据与时间

`GameEngine` 独占可变世界状态。物理、AI、伤害和回合逻辑以 **1/60 秒固定步长**更新；`requestAnimationFrame` 负责画面。React 以 **12.5 Hz 不可变快照**更新 HUD，不让 React 重渲染驱动物理。暂停时清除按键和累积时间，切出窗口不会产生大步穿墙。

### 碰撞与寻路

水平移动使用半径实体与 AABB 的分步扫掠、按轴滑动；垂直方向单独计算重力、起跳、落地支撑和顶棚碰撞。AI 使用同一套移动碰撞，而不是直接沿路径修改到任意坐标。

导航图覆盖 1,602 个可通行网格节点。每条相邻边预先检查实际半径与门柱等障碍，避免“两个端点都能站立，但中间穿过门框”的斜切问题。A* 使用八方向网格、最小堆和八方向距离启发式，输出路径再进行扫掠可见性平滑；阻塞检测触发重新寻路。

### AI 行为

AI 自主执行推进、守点巡逻、交战、回收炸弹、安放和拆除。T 按回合在 A 大/B 洞主攻路线之间切换，另有猫道与下 B 洞分队；CT 分守 A/B/中门，得知 C4 安放后转向目标点。视野要求距离、朝向与无遮挡射线，射击有反应延迟、瞄准误差、射速、弹药和换弹约束。没有视野的敌人不会直接受到 AI 伤害。

### 渲染与声音

静态建筑按材质/阴影状态合批。角色是头、躯干、双臂、双腿和装备的组合，腿部步行摆动；不是胶囊或柱状替身。第一人称武器使用独立的清深度渲染通道，保留模型自身遮挡，不会被贴近的墙裁掉。

Web Audio 为不同枪型合成不同噪声频谱、低频脉冲和衰减包络，还包含换弹、脚步、开镜、命中、击杀、安放、拆除、滴答、爆炸和胜负提示。AI 枪声与脚步按照距离衰减，并做左右声像定位。

## 验证与范围

已执行严格 TypeScript 检查、Vite 生产构建、Chromium 浏览器操作与逻辑回归，详见 [QA.md](./QA.md)。`tests/verify.html` / `tests/verify.js` 包含可重复运行的实际模块回归测试；执行 `npm run test:browser` 即可查看逐项结果，也可在开发服务器上访问 `/tests/verify.html`。开发模式会把引擎挂到 `window.dustline`，便于查看状态；生产构建不暴露该入口。

这是可游玩的**本地单人 + AI 原型**，不是联网游戏，也不包含服务器、反作弊、匹配、经济系统或官方地图/动画资源。UI 会适应小窗口，但触屏虚拟摇杆不在本项目范围内。项目与 Valve / Counter-Strike 无关联。
