# 归尘 · DUST, RETURNING

一部 4 分 12 秒（252 秒）的 Three.js 程序化短片，含片头与片尾。根据用户提供的章北海片段改编。全片 25 镜，所有造型、布景、纹理、动画、光照和特效均由代码生成。

## 放映

```sh
bun run build
bun run preview
```

打开终端显示的本地地址，点击「开始放映」。交付构建位于 `dist/index.html`，连同 `dist/assets/` 由静态服务器提供即可，不需要网络资源。无需安装依赖，使用平台已提供的离线工具链。

- 播放器提供播放、暂停、拖动时间轴、音量和全屏。
- 空格：播放 / 暂停；左右方向键：前后 5 秒；F：全屏。
- 首次点击播放才解锁声音。没有录制、生成或合成任何人声。

## 改编

影片保留「购买—加工—等待—袭击—归途」的因果链，删去价格交涉、弹药制作参数和大部分宏观背景。以陨石和茶杯组织意象，先呈现收藏者的小世界，再揭示章北海对这个世界的珍惜与他所作选择的矛盾。

| 时间 | 段落 | 视听设计 |
| --- | --- | --- |
| 00:00–00:21 | 天空与门槛 | 陨石、地球与孤身宇航员；切入胡同里的灯光 |
| 00:21–01:08 | 收藏者 | 木色、玻璃、茶与三块石头；从双人景别靠近人物 |
| 01:08–01:51 | 用途 | 冷青加工蒙太奇、地下室枪响、失去加工痕迹的碎石 |
| 01:51–02:06 | 路线 | 一次务实的会议，成为章北海的私人判决 |
| 02:06–02:42 | 轨道 | 车轮空间站、尚未成形的船坞、服内循环气流 |
| 02:42–03:13 | 人与判断 | 合影队列、面罩露出面孔；老人对地球的感慨 |
| 03:13–03:41 | 击发与等待 | 服内闷震；十秒凝视；白色泄漏粒子与通讯 |
| 03:41–04:12 | 代价 | 五名伤员、扶持撤离、无人回应的告解，切回空桌和茶杯 |

航天专家被表现为有经验、有局限的普通人。字幕中的判断属于章北海，不是影片对袭击的背书。片尾没有胜利音乐，也没有将未来作为已经得到的结果。

## 配音与编辑

`src/voice.js` 是唯一的配音清单，导出 `voiceCues`。每条仅含 `id`、`kind`、`speaker`、`text`、`delivery`、`start`、`end` 七个字段。所有语言字幕都由这份清单直接驱动，格式为 `【说话者】文本`，固定底部居中。秒数均相对完整影片，不相对镜头；`id` 可供后期逐条接入录音。

`src/film.js` 的 `EDIT` 是完整剪辑表。镜头状态、表演、摄影机和粒子由绝对时间计算，可暂停、重播或直接跳转。片名、地点卡与布景中的标牌属于非语音画面信息。

## 声音

`src/audio.js` 集中定义声音 cue 及 Web Audio 路由。所选九个 CC0 采样来自平台的 Kenney 库，均拷贝在 `src/assets/audio/` 并经 Vite 内联。原授权见该目录的 `LICENSE.md`。

地下室枪声采用采样冲击、短延迟反射及程序化混响叠加。真空中的外部击发、其他人的推进器与泄漏不产生空间传播声；只保留章北海服内的接触闷震、机械循环气流与通讯提示。配乐为程序化正弦泛音，不含人声。

## 实现

- `src/art.js`：Voxel Kit 角色装配、独立身体和服装贴图、方块道具和基础美术工具。
- `src/worlds.js`：七组原创建模布景；地球为带程序化海陆和云带的体素几何。
- `src/film.js`：25 镜绝对时间调度、摄影机、表演、面罩变化、受伤与协助撤离。
- `src/main.js`：统一 Cinematic Player、ThreeStage、控制与音频解锁。

人物全部遵循 Voxel Kit 原始骨架和部件比例。五官、衣缝、标识、面罩与裂纹均绘制在贴图上。没有外部图像、游戏资产、CDN 或第三方运行时库。
