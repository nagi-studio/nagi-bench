# DUST II — Strike / Protocol

React 18 + TypeScript + three.js 编写的浏览器第一人称射击原型。单机 5v5：玩家及 4 名 AI 队友对抗 5 名 AI。地图采用 Dust2 的核心路线拓扑与程序化低多边形建筑，包含 T / CT 出生点、A 大、A 点、中路及可通行中门、猫道、上下 B 洞、B 点与 B 门。

## 启动

需要 Node.js 20.19+ 或 22.12+，以及支持 WebGL 2、Pointer Lock、Web Audio 的桌面浏览器。

```bash
npm install
npm run dev
```

打开终端显示的本地地址（默认 `http://localhost:5173`），选择阵营、武器和开局模式，点击 **DEPLOY TO DUST II**。浏览器会捕获鼠标并启用音效。按 Esc 暂停；点击 **RETURN TO ACTION** 继续。

```bash
npm run build     # TypeScript 检查及生产构建
npm run preview   # 预览 dist
npm test          # 自动启动 Vite 与无头 Chrome，执行真实浏览器检查
```

测试需要 Node.js 22.12+，不增加第三方测试依赖，通过 Node 内置 WebSocket 使用 Chrome DevTools Protocol。自动寻找 Chrome / Chromium / Edge；特殊安装路径可用环境变量 `CHROME_PATH` 指定。测试使用端口 5174、9233，结束后关闭自行启动的进程。截图保存到 `.cache/`，该目录不参与构建。

部署界面可以选择 AK-47、M4A4、AWP，以及默认阵营手枪或沙鹰。手枪局第一回合全员只有 Glock / USP、刀及 25 点护甲；第二回合起使用常规装备和 100 点护甲。比赛为本地循环回合，没有经济购买系统或在线多人服务。

## 回合规则

- 每回合 3 秒准备，115 秒比赛。全员在出生点复活、恢复装备，双方累计比分。
- T 玩家开局持有 C4；玩家选择 CT 时，C4 由 T 机器人携带。持包者死亡后掉包，其他 T 走近自动拾取。
- A / B 点半径 6.5 米内，静止连续安放 3.2 秒。安放后 40 秒爆炸。
- CT 距离 C4 2.1 米内，静止连续拆除 5 秒。松开 E、移动或被击杀会中断并清空进度。机器人会指定拆包手，其他队员警戒。
- CT 全灭或 C4 爆炸：T 胜。T 全灭且未下包、成功拆除、未下包时超时：CT 胜。已经安放的 C4 在 T 全灭后继续倒计时。
- 不启用友军伤害；友军的身体会挡住子弹。队友接管继承该角色的血量、护甲、弹药和 C4 状态。

## 实现结构

| 文件 | 职责 |
| --- | --- |
| `src/game/engine.ts` | 唯一可变游戏状态、60Hz 固定物理更新、渲染循环、输入、战斗、AI 状态机、C4、回合及观战接管 |
| `src/game/map.ts` | 16 个连接区域、程序化建筑与标识、共享 AABB 碰撞体、逐轴移动与垂直碰撞、遮挡射线、二叉堆 A* |
| `src/game/models.ts` | 分离头身四肢、持枪动作、分区 Hitbox、七种枪刀、第一人称双手与 C4 几何体 |
| `src/game/weapons.ts` | 可扩展武器数据、弹匣 / 备弹、射速、散布、后坐力、护甲和部位伤害 |
| `src/game/audio.ts` | Web Audio 振荡器及噪声包络合成枪声、脚步、换弹、开镜、命中、击杀与 C4 提示 |
| `src/App.tsx`、`src/ui/` | React 部署、HUD、实时战术小地图、计分板、指南和设置 |
| `scripts/check.mjs` | 地图通行、碰撞、真实命中、AI、C4、胜负及实际鼠标键盘输入的浏览器集成检查 |

引擎每秒发布约 13 次不可变快照，React 通过 `useSyncExternalStore` 订阅；React 更新不驱动物理或渲染。three.js 的 `requestAnimationFrame` 与 60Hz 固定步长模拟分开。失去窗口焦点或释放指针锁时暂停，并清空按键。卸载时注销事件、停止 RAF、释放几何、材质、纹理、渲染器及音频上下文。

命中使用角色真实几何 Hitbox 的 Raycaster，按地图射线最近距离截断。头、胸、腹、手臂、腿对应 `2 / 1 / 1.12 / 0.78 / 0.65` 倍基础伤害；护甲按武器穿透率减伤。AK 后坐力与扩散更高，M4 更快且更稳定，AWP 开镜同时调整三维 FOV 与二维遮罩。

运行依赖仅 `three`、`react`、`react-dom`。没有模型、贴图、音频或字体资产下载，也没有运行时外部请求。建筑表面用 GLSL 噪声生成；A / B 等标识使用运行时 Canvas 绘字。所有几何、声音和 HUD 图形均在代码中生成。该原型还原核心路线和玩法，并非原版 BSP 或逐尺寸地图复刻。
