# Dust II · 5v5 —— React + TypeScript + three.js 第一人称射击原型

浏览器里直接运行的 Dust2 核心区域 5v5 爆破模式原型。**没有任何外部资产文件**：地图、角色、武器都由代码里的几何体
生成，贴图用 Canvas 程序化绘制，声音全部用 Web Audio 实时合成。运行时依赖只有 `three`、`react`、`react-dom`；
物理、寻路、AI 状态机、渲染循环都是自己实现的。

```bash
npm install
npm run dev        # 打开 http://localhost:5173
```

需要 Node ≥ 22.6（测试脚本直接用 Node 自带的 TypeScript 类型剥离运行）。

## 操作

| 按键 | 功能 |
| --- | --- |
| `W A S D` / `Shift` / `空格` | 移动 / 静步（不发出脚步声）/ 跳跃 |
| 鼠标 | 转视角（指针锁定） |
| 左键 / 右键 | 开火 / AWP 开镜（两档变焦），持刀时为重击 |
| `R` | 换弹 |
| `1` `2` `3` `5`（或 `4`）、`Q`、滚轮 | 主武器 / 副武器 / 刀 / C4、上一把武器、循环切换 |
| `E`（按住） | 在包点安放 C4 / 在 C4 旁拆除；阵亡观战时接管当前观察的队友 bot |
| 按 `5` 后按住左键 | 另一种安放 C4 的方式 |
| 阵亡后 左键 / 右键 | 切换观察的存活队友 |
| `B` | 长枪局购买菜单（冻结时间 + 开局 20 秒内、在出生区），数字键购买 |
| `Tab`（按住） | 计分板 |
| `Esc` | 暂停（释放鼠标） |

## 各项需求对应的实现

| 需求 | 实现位置 |
| --- | --- |
| Dust2 地图：T 出生点、CT 出生点、A大（含 A大门）、A点、中路 + **可穿过的中门**（一扇关、一扇开，留约 2m 通道）、猫道（坡道上到 A小）、B洞（上/下洞）、B点、B门 | `src/core/mapData.ts`（可行走区域 + 道具）、`src/core/world.ts`（没被任何区域覆盖的格子全部变成实心墙，所以地图天然封闭，也不会有缝隙） |
| 墙体和箱子都有碰撞 | `src/core/physics.ts`：竖直圆柱体 vs AABB，带台阶抬升、坡道、天花板和子步进（高速也不会穿过门板）。玩家和 AI 用同一套代码 |
| 类人角色：独立的头、躯干、双臂、双腿 | `src/client/render/characterView.ts`：颈、头、胸、腹、骨盆、上臂/前臂/手（用双骨 IK 握住枪）、大腿/小腿/靴子（走路循环）。CT 是深蓝制服 + 头盔 + 护目镜 + 蓝色臂章；T 是棕色夹克 + 黑色头套 + 红头巾/红臂章 |
| 可扩展的武器数据系统 | `src/core/weapons.ts`：每把枪一条数据（伤害、穿甲比例、射速、弹匣、扩散、后坐力、开镜、移速、音效档）。新增武器只需加一条数据和一个模型函数 |
| AK / M4 / AWP / Glock / USP / 沙鹰 / 刀 | 各有独立数值：AK 38 伤害、后坐力强（10 发后视角上扬约 15°）；M4 33 伤害、射速更高、上扬约 8.5°；AWP 140 伤害 + 两档开镜 + 2D 瞄准镜遮罩 + 开枪后自动退镜再开镜；沙鹰 31 伤害，介于手枪和步枪之间，弹匣 7 发。第一人称模型见 `weaponModels.ts` / `viewmodel.ts` |
| Hitbox 分区伤害 | `src/core/skeleton.ts`：头 / 胸 / 腹 / 手臂 / 腿。手臂 hitbox 由第三人称模型用的同一套 IK 姿势生成，所以看到打的就是能打中的。倍率：头 2.0（**身体的两倍**）、胸 1.0、腹 1.1、手臂 0.8、腿 0.65 |
| 护甲 | 仿 CS 公式：护甲按武器的穿甲比例减伤；头部只有戴头盔才受保护；腿部不受保护 |
| 手枪局 | `src/core/round.ts` 中的 `LOADOUTS.pistol`：第 1 回合（或在菜单勾选“每回合都是手枪局”）只有默认手枪（T 为 Glock、CT 为 USP-S）+ 刀，有防弹衣但没有头盔、没有拆弹器、不能购买 |
| C4 | 开局随机交给一名 T；持包者阵亡时掉落，任何 T 走过去即可捡起；在 A/B 点按住 3.2 秒安放，40 秒倒计时（蜂鸣会越来越快）；CT 拆除需 10 秒（带拆弹器 5 秒） |
| 回合胜负 | T 全歼 CT 或炸弹爆炸 → T 胜；CT 在未下包前全歼 T、拆包成功、或计时结束 → CT 胜。包已安放时，T 全部阵亡回合也会继续 |
| 阵亡后观战 / 接管 | 先有一段死亡镜头，之后第一人称观察存活队友（左/右键切换），按 `E` 接管该 bot |
| 5v5 AI | `src/core/ai.ts`：目标层（T：选定包点并按 A大 / 猫道 / B洞 / 中转B 路线推进，持包者稍晚出发，其他人护送；到点后安放并守包。CT：分站 A大、A小、中路、B点、B平台，看到 T 后回防，下包后回防并由最近的 CT 拆包）叠加战斗层（视野锥 + 视线射线检测、反应时间、瞄准误差逐渐收敛、压枪、点射/扫射、急停后开枪、左右晃身、AWP 开镜、被打后回头、听声辨位）。寻路：`src/core/nav.ts`，0.5m 网格 A* + 路径拉直，并带卡住检测 |
| HUD | `src/ui/Hud.tsx`：准星的间距就是真实的扩散锥投影到屏幕上的大小；血量/护甲；弹药面板（开火递减、换弹恢复，带换弹进度）；击杀播报（含爆头标记）；命中提示；受击方向；回合计时 / C4 倒计时；比分和存活人数；计分板；购买菜单 |
| 小地图 | `src/ui/Minimap.tsx`：常驻的 Dust2 俯视轮廓（由碰撞网格生成）、自己（箭头 + 视野锥）、队友、被己方看见的敌人、C4 位置（安放后闪烁） |
| 音效 | `src/client/audio/audio.ts`：AK/M4/AWP/Glock/USP-S（消音）/沙鹰各自不同的合成配方；分阶段的换弹声；脚步（有空间定位，隔墙会变闷）；AWP 开镜；命中声 / 爆头声；击杀提示；C4 安放按键声、蜂鸣、拆除咔哒声、拆除成功、爆炸；回合开始/结束提示音 |

## 架构

```
src/core/      纯 TS 模拟层（不依赖 three / DOM）→ 可在 Node 里无界面运行
  world.ts       区域网格 → 合并墙体、地板高度查询、射线检测、宽相位加速
  physics.ts     角色运动学
  nav.ts         导航网格、A*、路径拉直、连通分量
  skeleton.ts    身体尺寸、持枪姿势、双骨 IK、hitbox 与射线检测
  weapons.ts     武器数据 + 伤害模型
  character.ts   角色状态（玩家和 bot 共用）
  sim.ts         60Hz 定步长模拟：移动、武器状态机、射击判定、伤害、C4、视野发现
  round.ts       回合状态机（冻结 → 进行中 → 结束）、配装、胜负判定
  ai.ts          bot 分层状态机
  events.ts      模拟 → 表现层的事件（音效 / 特效 / HUD）
src/client/    表现层
  gameClient.ts  渲染循环：定步长模拟 + 按显示刷新率插值渲染、事件分发、观战镜头、HUD 快照
  render/        地图网格（合并成少量 draw call、世界坐标 UV）、角色、第一人称模型、特效、程序化贴图
  audio/         Web Audio 合成器
  input.ts       键盘 / 鼠标 / 指针锁定
  hudStore.ts    外部 store → React useSyncExternalStore
src/ui/        React 界面（菜单、HUD、小地图、准星）
```

**数据同步方式。** 模拟层是唯一的权威状态，以固定 60Hz 步进。渲染器按显示刷新率运行，在上一帧和当前帧之间插值位置。
鼠标视角在每帧直接写入。模拟层向事件队列推送事件，客户端每一步都会取空队列，驱动音效、特效和 HUD。React 通过
`useSyncExternalStore` 以约 20Hz 读取 HUD 快照。准星和小地图更新频率更高，它们在自己的 `requestAnimationFrame`
循环里直接读取数据，不会触发 React 重新渲染。

## 测试

```bash
npm test               # 下面全部
npm run test:syntax    # 用 Node 的 TS 剥离解析每个 .ts 源文件
npm run test:nav       # 地图生成、所有关键区域连通、寻路耗时
npm run test:mechanics # 爆头 = 身体 2 倍、护甲、AWP 一枪毙命、hitbox 射线、AK vs M4 后坐力、中门可穿过、坡道、
                       # 手枪局配装、下包 / 拆包 / 爆炸 / 掉包 / 捡包
npm run sim -- 30      # 无界面 10 个 bot 对战 30 回合：胜负结算、下包、拆包、穿墙检查、性能
npm run test:client    # 用最小 three / DOM / WebAudio 替身跑真实的 GameClient 几千帧
                       # （渲染循环、第一人称模型、特效、音效路由、HUD、观战、接管、购买）
```

我自己最近一次无界面跑 30 回合的结果是 15:15，其中 A、B 两点都有下包，也有拆包成功的回合；全程没有角色卡进几何体。
每个模拟 tick 平均约 0.06ms。
