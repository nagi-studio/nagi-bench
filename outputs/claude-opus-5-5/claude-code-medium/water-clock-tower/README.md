# 水运仪象台 · 30 秒 3D 物理科普短片

北宋苏颂、韩公廉主持建造的水运仪象台（1088 年），如何靠水驱动、按时报时？
本片用约 32 秒讲清整条传动链：

天池 → 平水壶（恒水位，恒定流量）→ 受水壶（变重）→ 格叉（称重）→ 天条 → 天衡 → 天关（放行一格）→ 枢轮转一格、天关复位（天锁防倒转）→ 地毂 → 天柱 → 齿轮 → 浑象、浑仪 / 机轮 → 拨牙 → 木人击钟、时辰牌报时；退水由升水轮提回天池。

## 运行

```bash
bun run build        # 产物在 dist/
```

- 直接双击 `dist/index.html` 即可离线播放（构建为经典脚本，`file://` 下可用；无任何网络请求）。
- 浏览器通常要求用户手势后才能出声：点击右下角“🔊 点击开启声音并从头播放”。播放结束后可“重新播放”。
- 开发：`bun run dev`。

## 技术要点

- **物理（`src/physics.js`）**：Rapier3D（`@dimforge/rapier3d-compat`）实时计算全部机械运动，固定步长 1/150 s。
  - 水滴是刚体小球，从平水壶出水口以恒定速度喷出，落入受水壶。
  - 12 只受水壶用带限位的转动关节铰接在枢轮上；壶的托销压在格叉托板上，格叉与枢权配重构成“秤”。
  - 格叉经“天条”（Rapier 绳索关节，只拉不推，略带松弛）拉动天衡；天衡左端的天关卡住辐端销。壶满 → 格叉下沉 → 天衡翘起 → 天关抬开 → 枢轮在满壶重力下转过一格 → 格叉复位、天关落下卡住下一根销；天锁（重力棘爪）防止倒转。
  - 枢轮 → 地毂 → 天柱 → 机轮 / 浑象 / 浑仪 之间的齿轮啮合，用按转动惯量交换角动量的冲量约束实现（含角度漂移修正），负载会反传回枢轮。
  - 机轮上的拨牙与木人杠杆、钟之间是真实碰撞：拨牙推起木人尾杆，滑过后木人回摆击钟。
  - 模拟是确定性的：同样的初值每次得到同样的事件时刻（已验证 Bun/JavaScriptCore 与 Chromium/V8 结果一致），字幕按这些物理事件的时刻编排；部件高亮、音效、走格计时 HUD 直接读取实时物理状态与碰撞事件。
- **画面（`src/scene.js`、`src/textures.js`）**：three.js；所有模型由代码构建，所有贴图（木纹、青铜、星图、时辰牌文字等）在运行时用 Canvas 生成，无任何外部资产文件。传动镜头中墙体做“X 光”半透明。
- **声音（`src/audio.js`）**：全部用 Web Audio API 运行时合成——五声音阶拨弦配乐与低音持续音、水流噪声、擒纵“嗒”声、钟声（非谐泛音）、齿轮低鸣；总线经压缩器与限幅器，离线渲染测得峰值约 −3 dBFS，不爆音。
- **镜头与字幕（`src/timeline.js`）**：手写镜头关键帧与字幕（题目允许），机械运动不做任何手写动画。

## 自检工具（`tools/`，不参与构建）

- `bun tools/sweep.mjs '[{...}]'`、`bun tools/events.mjs`：无头运行物理，检查走格规律与关键事件时刻。
- `bun tools/chromesim.mjs`：在无头 Chromium 中运行同一物理，确认跨引擎一致。
- `bun tools/shots.mjs <dir> <times> @`：按影片时间确定性截图（读取 `tools/query.txt` 作为 URL 参数）。
- `bun tools/audiotest.mjs`：OfflineAudioContext 离线渲染整片声音，统计峰值/响度。
- `bun tools/filetest.mjs`：以 `file://` 打开 `dist/index.html` 验证离线可运行。
