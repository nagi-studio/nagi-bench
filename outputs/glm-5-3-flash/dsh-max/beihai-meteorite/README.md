# 陨石子弹（Meteor Bullets）

一部完全在浏览器中运行的**程序化三维短片**：以 Three.js 与体素（voxel）美术语言，
改编自刘慈欣《三体Ⅱ·黑暗森林》中「增援未来」的章北海段落。

- 片长：**328 秒**（≤ 360 秒硬上限），片头片尾计入。
- 交付：`bun run build` 产出标准 Vite 构建物 `dist/index.html` + `dist/assets/`，
  直接打开即可播放（播放、暂停、跳转、音量、全屏、底部字幕齐备）。
- 一切画面、模型、贴图、音乐与音效均为运行时代码生成——无任何外部资产、音频文件或 CDN。

## 改编思路（导演阐述）

原文素材被重排为「谜面 → 谜底 → 兑现」的三幕结构，而不是逐段复述：

1. **冷开场（0–13）**：高轨道俯瞰体素地球与太空电梯，旁白定下主题——
   「离星空最近的一次，也是离失败最近的一次」。
2. **第一幕·谜面（13–97）**：胡同→收藏者的老宅。全套正反打覆盖
   （入口宽景、双人过肩、托盘特写、举杯、定价、付款），终落在那句
   「就算表示我对要送的人的尊重」——第一记暗雷。收藏者的地质学演讲、
   火星陨石珍宝等支线被舍弃，只保留人物与交易。
3. **第二幕·谜底（97–161）**：车间（数控机床切削、36 根陨石圆柱的俯拍阵列）
   与地下室（起弹、粘接、试射——全片唯一一声真实枪响，强反射混响 +
   耳鸣余音）。章北海给常伟思的那句请示作为「记忆回声」叠在机器声上。
4. **第三幕·兑现（161–328）**：入轨大远景 → 悬浮独白 → 日落合影 →
   真空击发（外部完全无声：只有宇航服内传导的闷震、心跳与无线电）→
   「陨石雨」的谎言得逞 → 归途与尾声（父亲之星）。

省略与重组：常伟思、黄河站内部会议、定位单元细节、子弹空气动力学解释等
全部删除或压缩为一句台词/一个镜头；「他们也无辜」的内心辩驳放在击发声中
落点，作为全片道德重心。

## 声音设计（全部 Web Audio 运行时合成）

- 弦乐垫（pad）：每幕一个和弦与亮度，冷开场-老宅-车间-太空-尾声五种情绪。
- 环境：胡同（风、市声、鸟）、老宅（低鸣 + 机械挂钟滴答）、车间（50 Hz 电唐 +
  主轴啸叫）、地下室（滴水 + 市电嗡鸣）、太空（次声嗡鸣 + 缓慢气涌）、
  宇航服（风机 + 呼吸循环 + 阀门敲击）。
- 物理：地下室枪声 = 直达声 + 卷积混响（程序生成 IR）+ 两道板墙回声 + 低频轰鸣；
  真空中的 30 发击发只有**击锤咔哒与传导到身体的闷震**（低通处理），
  命中、舱门、他人推进器一律无声，只走无线电与主观心跳。
- 全部待配音台词集中于 `src/core/voice.ts` 的 `VoiceCue[]`（id/kind/speaker/
  text/delivery/start/end 七字段），字幕由播放器按该清单渲染为
  `【说话者】文本`。

## 目录结构

```
index.html            入口（含加载提示）
src/main.ts           装配：渲染器、播放器、舞台、音频总线、控制条、叠加层
src/core/timeline.ts  分镜表：场次、摄影机轨道（aim 解算）、黑场/片名/瞄准镜叠加
src/core/camera.ts    摄影机轨道（关键帧 + 硬切 + 手持微晃）
src/core/voice.ts     ★ 配音清单（VoiceCue[]）
src/core/sound.ts     ★ 音效工厂 + SoundCue[]（Web Audio 全合成）
src/core/cast.ts      演员贴图（64×64 身体/服装双层皮肤）与人物装配
src/core/props.ts     体素道具（手枪、瞄准镜、茶具、弹药箱……）与房间合并几何
src/world/ground.ts   胡同 / 老宅 / 车间 / 地下室四个地面场景
src/world/space.ts    地球、轮站、太空电梯、合影人群、弹道与命中特效
test/smoke.ts         无头冒烟测试（伪造 DOM，全片逐帧驱动 + 跳转扫描）
test/preview.ts       构图报告（把被摄对象投影到 NDC 验证分镜）
test/drive.ts         CDP 驱动真实浏览器：点击播放、截图、查控制台
```

## 运行

```bash
bun run build     # 产出 dist/
bun run check     # tsc --noEmit
bun test/smoke.ts # 无头冒烟测试（可选）
```

播放页 `?fast=1` 参数可关闭阴影、限制像素比（无头截图/低性能设备用）。

## 确定性

所有镜头、表演、粒子、光效都是**绝对时间的纯函数**：任意跳转、暂停、回放
都精确复原同一画面。音效 cue 由播放器时间轴触发，`sustain` 环境声在跳转后
按偏移量重启。
