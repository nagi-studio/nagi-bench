# DE_DUST2 5v5 — Procedural FPS Prototype

一个完全在浏览器中运行的 3D 第一人称射击原型：以代码程序化复刻 **Dust2 核心区域**，
5v5 人机对抗、C4 下包/拆包回合制、分区 Hitbox 伤害、程序化合成音效。

**零外部资产** —— 没有任何模型 / 贴图 / 音频文件。地图、人物、武器、准星、音效全部由代码生成。
第三方库只有 `three` / `react` / `react-dom`；寻路、物理、渲染循环、AI、状态机均为手写实现。

## 快速开始

```bash
npm install
npm run dev        # 打开 http://localhost:5173，点击「进入游戏」即可游玩
```

> 建议 Chrome / Edge。点击画面捕获鼠标，`Esc` 释放鼠标呼出菜单。

## 玩法规则（CS 标准）

- **第 1 回合为手枪局**：全员只有默认手枪（T: Glock-18 / CT: USP）+ 匕首，无护甲。
- 之后每回合：T 拿 AK-47、CT 拿 M4A4，护甲 + 头盔 100。
- 回合开始 C4 随机交给一名 T；持包者阵亡后 C4 掉落，其他 T 走过即可拾起。
- 持包 T 在 **A 点 / B 点** 区域内按住 `E` 3.2s 安放；安放后 40s 倒计时。
- CT 站在 C4 旁按住 `E` 10s 拆除。
- **胜负**：T 方全灭且未下包 → CT 胜；CT 全灭或 C4 爆炸 → T 胜；成功拆包或时间耗尽 → CT 胜。
- 先赢 8 回合获胜。

## 武器与伤害

| 武器 | 伤害 | 射速 | 弹匣 | 特点 |
| --- | --- | --- | --- | --- |
| AK-47 | 36 | 600 RPM | 30/90 | 高伤害、剧烈后坐力（准星扩散 + 视角上扬） |
| M4A4 | 33 | 666 RPM | 30/90 | 低后坐力、高射速 |
| AWP | 115 | 41 RPM | 10/30 | 一击致命、右键开镜、移动极慢 |
| Glock-18 / USP | 28 / 35 | 400 / 352 | 20/60 · 12/60 | 手枪局配枪 |
| Desert Eagle | 63 | 267 | 7/35 |介于步枪与手枪之间 |
| 匕首 | 55 | — | — | 近战 1.9 m |

- Hitbox 分区：**头 ×2.0 / 胸 ×1.0 / 腹 ×1.25 / 手臂 ×0.9 / 腿 ×0.75**，另有距离衰减。
- 护甲按武器穿甲值（armorPen）减免：`实际伤害 = 伤害 × armorPen`，护甲吸收剩余部分的一半。

## 地图（程序化 Dust2）

T 出生点、CT 出生点、A 大（Long A + Long Doors）、A 点（高台 + 默认包点箱）、
中门（含可穿过的门体与门板）、猫道（Catwalk + A Short）、B 洞（Upper/B Tunnels）、
B 点，全部按 Dust2 实际走位连通（由离线测试自动验证）。
墙体 / 箱子 / 油桶全部有物理碰撞，玩家与 AI 均无法穿墙。

## 架构

```
src/
  game/
    mapdata.ts    Dust2 平面数据：可行走区域 / 坡道 / 门洞 / 箱子 / 包点 / 战术点位
    world.ts      占据网格 + 高度场：碰撞、视线 (LOS)、A* 寻路、几何合并、子弹射线碰撞体
    weapons.ts    数据驱动的武器注册表（伤害/射速/扩散/后坐力/音效参数/命中倍率）
    character.ts  战斗单位（玩家与 AI 共用）：移动物理、开火、换弹、命中区域、生命护甲
    bot.ts        AI 状态机：感知 → 交战（瞄准/走位/点射）→ 目标（路线/下包/防守/回防/拆包）
    humanoid.ts   程序化人形骨骼：头/躯干/双臂/双腿 + 第三人称持枪模型 + 动画
    viewmodel.ts  第一人称武器模型：bob / sway / 后坐 / 换弹 / 拔枪 / 挥刀动画
    render.ts     three.js 静态场景：贪心合并的墙/地/箱、天空、光照阴影、门体
    textures.ts   Canvas 程序化贴图（沙墙 / 地面 / 木箱 / 金属 / 包点标记 / 天空）
    audio.ts      Web Audio 程序化音效（枪声/换弹/脚步/开镜/命中/C4/爆炸/击杀）
    effects.ts    弹道曳光、弹孔火花、血液、枪口焰、爆炸（对象池）
    engine.ts     全局引擎：渲染循环、物理帧、回合与 C4 状态机、观战/接管、HUD 同步
    bridge.ts     引擎 → React 的 HUD 快照通道
    minimap.ts    雷达：静态地图轮廓 + 自己/队友/被发现敌人/C4
    player.ts     指针锁定键鼠输入
  ui/             HUD、菜单、计分板、瞄准镜遮罩
  App.tsx         挂载 canvas、菜单流转、指针锁定
```

**三层数据同步**：引擎以固定节奏推进物理与 AI（可加速子步骤），
60fps 的数据（准星扩散、雷达）直接写 DOM/Canvas；10Hz 的 HUD 快照经
`bridge.ts` 推给 React（`useSyncExternalStore`），事件类信息（击杀播报）随快照分发。

## 离线测试（不需要浏览器）

```bash
npm run test:map      # ASCII 打印地图 + 验证所有关键区域互相可达 + 检查地形断裂
npm run test:sim      # （预留）逻辑仿真
node scripts/test-damage.ts   # 伤害模型：爆头 2×、护甲、衰减、穿墙阻挡
node scripts/sim.mjs 90 8     # 8 倍速 AI 对战仿真（回合/击杀/下包/拆包统计）
node scripts/scenario.mjs     # 无头浏览器机制测试：观战/接管/开镜/下包/爆炸/拆包/拾包
```

`sim.mjs` / `scenario.mjs` 需要 `puppeteer`（仓库默认 `PUPPETEER_SKIP_DOWNLOAD`，
如需运行请先 `npx puppeteer browsers install chrome`）。

## 已知取舍

- 角色与武器为方块拼装的程序化模型（无外部资产的前提下的风格化取舍）。
- 经济系统简化为按回合自动配枪（武器数据结构已可扩展出购买菜单）。
- 阴影与合并几何体针对中端设备调优；软件渲染（无 GPU）下帧率较低属正常。
