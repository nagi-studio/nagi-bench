# DUST // 2 · React + Three.js 5v5 原型

一个不依赖外部模型、贴图或音频文件的浏览器第一人称射击原型。地图、角色、枪械、C4 和音效全部由代码生成。

## 启动

```bash
npm install
npm run dev
```

然后打开 Vite 输出的本地地址。生产构建使用 `npm run build`。

## 操作

- 鼠标点击：锁定指针；鼠标移动：视角；左键：开火；右键：AWP 开镜
- `WASD`：移动，`Shift`：疾跑，`Space`：跳跃
- `1 / 2 / 3`：主武器 / 手枪 / 刀，滚轮：循环武器，`R`：换弹
- `E`：拾取 C4、在 A/B 点下包或拆包
- 阵亡后 `Space` 切换存活队友，`Enter` 接管当前队友
- 第一回合是标准手枪局；回合结束后自动进入全枪械回合，`N` 可立即开始下一回合

地图包含 T 出生、CT 出生、A 大、A 点、中门、猫道、B 洞和 B 点，AI 使用自实现的导航图、视线遮挡检测、交战状态机和 C4 目标逻辑。
