这是一座由程序生成的神话大陆：世界树尤克特拉希尔在北方撑起天空圣殿，矮人余烬王城在西方燃着符文之光，太阳金字塔在东方沙漠守望，法师塔与龙祭坛、巨石传送门散落在荒野。全部使用体素逐块搭建，可挖掘、可改造。

  • 🌍 无限地形：改良柏林噪声 fBm，大陆 / 山脉 / 海洋 / 沙滩 / 森林，出生点周围已预生成神话建筑群，远走则无限延伸。
  • 🧱 9 种方块：草地 / 泥土 / 石头 /橡木 / 树叶 / 木板 / 沙子 / 玻璃 / 石砖 / 发光符文 / 水 / 黑曜石 / 汉白玉，左键挖右键放。
  • 🕹️ 第一人称物理：跳跃 / 重力 / 碰撞 / 游泳 / 飞行(F)，完整昼夜切换(N)。
