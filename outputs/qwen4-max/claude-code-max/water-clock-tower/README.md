# 水运仪象台 · 30 秒 3D 科普短片

北宋苏颂水运仪象台的浏览器 3D 科普短片：讲清「水如何驱动、如何按时报时」的完整因果链。
全部机械运动由 **Rapier 物理引擎实时求解**；镜头与字幕为时间轴驱动；配乐/音效全部由
**Web Audio API 运行时程序化合成**；无任何外部模型、贴图、音频资产。

## 运行

```bash
bun run build      # Vite 构建 + 内联 JS/CSS 到 dist/index.html
```

- `dist/index.html` 已内联全部脚本/样式（Rapier WASM 以 base64 内联），**离线双击即可打开**，无任何网络请求。
- 也可用任意静态服务器服务 `dist/`。
- 开发：`bun run dev`（Vite）。
- 物理自检（Node，无渲染）：`bun run test:sim`。

## 传动链（每一步都由物理积分）

1. **恒流**：渴乌向计量斗注水（水滴为刚体），平水壶溢流保持水位恒定。
2. **擒纵**：计量斗水重压倒天衡复位弹簧 → 杠杆倾翻（纯物理）→ 触发枢轮关节伺服步进一格（恰 10°），
   同时斗水泻入受水壶；受水壶随轮转过 ~45° 倾覆倒水，完成水驱动闭环。
3. **齿轮**：枢轮轴小齿轮 → 正齿轮 → 冠齿轮/灯笼齿轮 → 天柱立轴。下游轴以「枢轮实测转角 × 齿比」
   为目标的力矩受限关节位置电机传动（物理伺服，齿比精确：0.5 / 1.5 / 4），齿面保留用于视觉啮合。
4. **仪象**：天柱带动浑象（星 globe）与浑仪旋转。
5. **报时**：天柱经增速齿轮带动报时机轮，木人槌头以接触力事件击钟/鼓（悬挂摆动产声）。

## 技术

- three@0.180.0 渲染（Phong 材质 + 程序化 canvas 星空/夜空贴图，软件渲染友好）。
- @dimforge/rapier3d-compat@0.21.0 物理（固定 60Hz 步长，子步追赶墙钟，低帧率下影片节奏不变）。
- 影片时钟自脚本加载起跟踪墙钟；物理快进补齐 boot 耗时。
- 音频：五声音阶拨弦（Karplus-Strong）配乐 + 夜风/水声环境 + 擒纵咔嗒/钟/鼓/水花音效，
  master 经 DynamicsCompressor 限幅，音量适中不爆音。首次点击解锁声音（预览环境自动播放）。

## 交互

- 点击画面：开启声音；右上 ♪：静音；片尾「重播」：重新求解整段机构。
- URL 参数：`?speed=2` 加速、`?mute=1` 静音（调试用）。
