# 水运仪象台 · 30 秒 3D 科普短片

一部可在浏览器直接打开的 3D 科普短片(约 32 秒),讲清北宋苏颂《水运仪象台》如何**以水驱动、按时报时**。
面向从未听说过它的观众:全景 → 水路 → 擒纵 → 齿轮传动 → 木阁报时 → 尾声,六镜头逐层拆解"每一步如何带动下一步"。

## 运行 / 构建

```bash
bun run build      # 产出 dist/(vite,--configLoader native 以适配只读 node_modules)
bun run dev        # 开发服务器
```

构建产物 `dist/index.html` **离线可直接双击打开**(base 为相对路径,无任何网络请求、无外部模型/贴图/音频文件)。
调试参数:`?seek=N` 快进物理仿真 N 秒,便于逐镜头检查。

## 技术栈

- **three@0.180.0** — 渲染。全部几何体/贴图运行时程序化生成(Lathe 屋檐、Canvas 匾额/棂花、实例化木人/水珠)。
- **cannon-es@0.20.0** — 物理。**所有机械运动均由物理引擎实时解算**,视觉层每帧仅同步刚体位姿:
  - 枢轮:刚体+铰链。受水壶注水增重 → 解除制动 → 重力矩驱动转过一壶 → 制动擒住(擒纵节拍)。
  - 天衡/天关:刚体杠杆+铰链;水满施加"水压"力矩 tipping,配重伺服复位。
  - 传动链:各级齿轮轴以铰链电机按传动比耦合,速度取自上一级刚体实时角速度(外啮合反向)。
  - 报时:鼓槌/钟槌为真实摆体,受冲量摆动并与鼓/钟**碰撞**后触发声音;钟受撞摇摆。
  - 水:每一滴都是球形刚体,落入受水壶、随轮倾泻、退回水池(池满回收)。
  - 控制逻辑只决定"何时注水/松锁/施加多大力",绝不直接设置刚体位置或角度。
- **Web Audio API** — 全部声音运行时合成:环境风声+宫音 drone、古琴式拨弦、水流带通噪声、擒纵咔嗒、鼓、编钟式铃;经压缩器与总音量控制,不爆音。
