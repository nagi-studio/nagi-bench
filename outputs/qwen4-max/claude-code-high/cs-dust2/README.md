# Dust2 5v5 — 浏览器第一人称射击原型

**React 18 + TypeScript + three.js**，从零实现的 CS 风格 5v5 对战原型。
地图、角色、武器、贴图全部由代码程序化生成，音效由 Web Audio 实时合成 —— **零外部资产文件**。
第三方运行库仅 `three` / `react` / `react-dom`；寻路、物理、状态机、渲染循环均为自研。

## 快速开始

```bash
npm install
npm run dev        # 打开 http://localhost:5173
```

需要 Node 18+（推荐 22+）。点击「进入战场」锁定鼠标即可游玩。

## 操作

| 按键 | 功能 |
|---|---|
| WASD / 空格 / Shift | 移动 / 跳跃 / 静步 |
| 鼠标左键 / 右键 | 开火 / AWP 开镜（刀为右键重击） |
| 1 / 2 / 3 | 主武器 / 副武器 / 刀 |
| R / E / G | 换弹 / 安放&拆除 C4 / 丢弃 C4 |
| B | 冻结时间购买（手枪局禁用） |
| Tab | 计分板 |
| 阵亡后 空格 / F | 切换观战队友 / 接管该队友 |
| Esc | 暂停（释放鼠标） |

## 玩法与规则

- 你初始为 **CT**，带 4 名 AI 队友对抗 5 名 T；半场（第 8 回合）换边，先到 **8 分**获胜。
- **手枪局**（第 1、8 回合）：全员默认手枪（T=Glock，CT=USP）、无主武器、无护甲。
- **C4**：回合开始随机交给一名 T；持包者阵亡掉落，其他 T 可捡起；在 A/B 点按住 E 安放（3.2s），
  40 秒倒计时；CT 靠近按住 E 拆除（10s）。
- **胜负**：T 歼灭 CT 或 C4 爆炸 → T 胜；CT 歼灭 T（未下包）、拆包成功或时间耗尽（未下包）→ CT 胜。
- **Hitbox 分区**：头 / 胸 / 腹 / 手臂 / 腿，爆头 = 身体 2 倍；护甲按减伤系数吸收身体伤害。
- 武器手感：AK 高伤害大后坐力、M4 稳定高射速、AWP 单发致命+开镜（3D 变焦 + 2D 镜罩）、
  Glock / USP / 沙鹰（伤害介于手枪与步枪之间、7 发弹匣）、刀。

## 地图

程序化复刻 Dust2 核心区域，按真实走位连通：

```
B点 ── B门 ── CT出生点 ── CT坡 ── A点
 │               │                │ ↑
B洞上层        中路上段          猫道(抬高+台阶)
 │               │ 中门(可穿过/可穿射)  │ A大
B洞下层 ────── 中路下段          │ A大门
 │               │ 自杀巷        │ A大外场
 └────────── T出生点 ────────────┘
      （B洞另有一条通道连中路下段）
```

地图以「可行走矩形区域」描述，2m 网格自动生成墙体；中门 / A大门 / B门为双开木门，
中间留可行走缝隙，木板可被子弹穿透（伤害衰减）。所有墙体、箱子、门均有 AABB 碰撞。

## 架构

模拟核心与渲染完全解耦 —— 纯 TS  simulation 可在 Node 中无头运行（见测试）：

```
src/
├── game/
│   ├── math.ts        向量/角度/种子随机（零依赖）
│   ├── types.ts       共享类型：角色、武器槽、事件、HUD 快照
│   ├── weapons.ts     数据驱动武器表 + Hitbox 倍率 + 护甲公式
│   ├── map.ts         Dust2 区域定义 → 网格 → 墙体/门/箱子碰撞体
│   ├── nav.ts         网格 A* + 视线字符串平滑
│   ├── physics.ts     AABB 分轴移动、自动台阶、射线检测、LOS
│   ├── simulation.ts  全局状态引擎：回合流程、C4、命中判定、视觉共享
│   ├── ai.ts          AI 状态机：索敌/交战/寻路/下包/拆包/捡包/驻守
│   ├── audio.ts       Web Audio 程序化音效（枪声/换弹/脚步/开镜/C4/爆炸…）
│   ├── textures.ts    Canvas 程序化贴图（砂岩/木地板/箱子/木门）
│   ├── character.ts   类人角色骨架：头/躯干/双臂/双腿 + 持枪姿态 + 行走/倒地动画
│   ├── viewmodel.ts   第一人称武器模型（含手臂）与第三人称武器共用构建器
│   └── engine.ts      three.js 渲染层：固定步长循环、输入、特效、小地图、HUD 桥
├── ui/                HUD / 小地图 / 击杀播报 / 计分板（React）
├── App.tsx            引擎生命周期 + 菜单/暂停/结算覆盖层
└── main.tsx / styles.css
```

**三层同步模型**：
1. `GameSim.update(1/60)` 固定步长推进纯逻辑（物理帧），产生 `SimEvent[]`；
2. `GameEngine` 每帧消费事件 → 驱动 three.js 渲染、粒子/曳光、Web Audio，并把鼠标/键盘
   输入转成 `PlayerInput` 喂回模拟；
3. 引擎以 10Hz 向 React 发布不可变 `HudState` 快照（`onHud` 回调 → `setState`），
   React 只读渲染 HUD，不参与逐帧逻辑。小地图由引擎直接绘制到 React 挂载的 canvas。

**AI 状态机**：`move / engage / plant / defuse / pickup / hold`。
视野索敌（距离 + FOV + 墙体 LOS 射线，被打会警觉）、反应延迟、点射控制、 strafing、
A* 寻路 + 卡墙检测重寻路、CT 接触轮转与抱团回防、T 分工（主攻/骚扰/自由人）、
下包/拆包决策（拆包前评估威胁，倒计时逼迫 ninja 拆包）。

## 离线测试（无需浏览器 / 无需安装依赖，Node 22.18+）

模拟核心零依赖，可直接用 Node 原生 TS 支持运行：

```bash
npm run verify      # 地图连通性(BFS)、门可穿过/可穿射、碰撞不穿墙、台阶、A*、武器数值
npm run rulestest   # 手枪局配置、下包/拆包/爆炸/歼灭/超时胜负、掉包捡包、半场换边、接管
npm run simtest     # 5 个随机种子 × 10 名 AI 完整比赛无头模拟（含 NaN/越界检查）
npm test            # 以上全部
```

另有（需要 bun，可选）：`bun scripts/syntax-check.mjs` 全文件语法检查、
`bun scripts/bundle-check.mjs` 全模块导入/导出打包校验。

## 已知限制

- 原型定位：无经济系统（购买免费）、无友军伤害、角色间无碰撞体积。
- AI 为规则状态机而非行为树/学习模型；枪法随技能值抖动。
- 阴影为单方向光 2048 PCF 软阴影，低端设备可在 `engine.ts` 关闭 `shadowMap`。
