# Dust Protocol — procedural Dust2 FPS

```bash
npm install
npm run dev
```

Open the local Vite address, click the viewport once to lock the pointer and begin.

- `WASD` move, `Space` jump, mouse aim, left click fire, right click scope (AWP)
- `R` reload; `1` / `2` / `3` select primary / secondary / knife
- `4` equips AWP after the pistol round; `5` equips Desert Eagle
- Hold `E` in a bombsite with C4 to plant, or at armed C4 as CT to defuse
- `Q` cycles/takes over a surviving teammate

All map meshes, characters, guns, labels, minimap art and sounds are generated at runtime in code. No model, texture, or audio asset is loaded.
