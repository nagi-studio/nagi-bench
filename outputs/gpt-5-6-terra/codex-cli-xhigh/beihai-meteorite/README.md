# 北海陨星

一个 200 秒的 Three.js 程序化体素科幻短片。故事从冰下观测站收到一枚不该坠落的信标开始：维修员玛拉在站体失压前把它送回天空，终于等到遥远的回应。

## 运行

```bash
bun run build
bun server.js
```

打开 `http://localhost:3000`。点击“开始放映”后才会启用 Web Audio；没有生成或包含人声。空格暂停，方向键跳转，`M` 静音，`R` 重播。

`src/main.js` 中导出的 `voiceCues` 是配音交付清单，也是字幕的唯一数据源。每条都固定包含 `id`、`kind`、`speaker`、`text`、`delivery`、`start`、`end`。所有模型、粒子、光线、屏幕颗粒与音效均在代码内生成；未使用贴图、CDN 或音频素材。室内段有风声、脚步、报警与闷响；离开气闸后只保留航天服内的低频结构震动和无线电提示，不把真空中的推进器处理成可听见的外部声源。
