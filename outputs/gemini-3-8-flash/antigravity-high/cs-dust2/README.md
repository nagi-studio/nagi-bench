# CS Dust2 5v5 FPS Prototype (React + TypeScript + Three.js)

从零开发、可在浏览器直接运行的 3D 第一人称射击原型，纯代码程序化复刻经典 **CS:GO / CS2 Dust2（炙热沙城 II）5v5 对局**。

---

## 🌟 核心特性与技术实现

### 1. 完整 Dust2 地图拓扑（空间尺度合理、零外部资产）
- **完整经典区域**：
  - **T 出生点 (T Spawn)**：出发平台与三向分流通道。
  - **A大 (Long A)**：A门房体 (Long Doors)、A大坑 (Pit)、A大拐角 (Corner)、蓝箱掩体、A大平地与上A包点斜坡。
  - **A包点 (A Site)**：1.5米高台、Goose 拐角、经典大三箱 (Triple Boxes)、Default 下包箱、A小台阶与连接 CT 出生点的斜坡，墙壁带有程序化喷漆标记。
  - **中路与中门 (Mid & Mid Doors)**：Top Mid、Suicide 斜坡、Lower Mid、**可穿过的中门门体（左右门扇倾斜开启，保留经典狙击门缝，玩家和 AI 均可穿过并射击）**、CT Mid。
  - **猫道 / A小道 (Catwalk / Short A)**：从 Lower Mid 台阶直上 Catwalk，经直角拐角直接俯瞰并连通 A 包点。
  - **B洞 (B Tunnels)**：Upper Tunnel 拱顶支柱通道、Lower Tunnel 台阶连通中路、B洞出口拱门。
  - **B包点 (B Site)**：0.8米包点木质/石质平台、B门 (B Doors)、B洞窗口 (B Window 跳箱)、汽车掩体箱群与后点箱。
  - **CT 出生点 (CT Spawn)**：北部广场，双向连接 A 斜坡与中路。
- **物理碰撞与寻路**：
  - 所有墙体、箱子、门扇和台阶均具备 3D AABB 碰撞体，玩家与 AI 均无法穿墙。
  - 自动台阶跨越 (Step-up) 与滑墙物理响应。

### 2. 程序化类人型角色（拒绝单柱几何体敷衍）
- **解剖学层级结构**：
  - 骨骼层级：骨盆 (Pelvis) -> 躯干腹部 (Stomach) -> 胸腔战术背心 (Chest & Plate Carrier) -> 颈部 -> 独立头部 (Head)。
  - 四肢：左/右大臂 (Upper Arm) -> 前臂 (Forearm) -> 战术手套 (Hand)；左/右大腿 (Thigh) -> 小腿 (Calf) -> 作战靴 (Boot)。
- **阵营外观差异**：
  - **CT (反恐精英)**：海军蓝深灰特战制服、防弹头盔配防弹护目镜/面罩、单兵通讯战术耳机。
  - **T (恐怖分子)**：荒漠卡其长裤、橄榄绿战术战术马甲、红色/土黄色防风阿拉伯头巾 (Keffiyeh) 与飞行员墨镜。
- **持枪战术姿态与程序化骨骼动画**：
  - 默认双手端枪战术待命姿态，枪口朝向随视角与准星同步。
  - 走路双腿双臂正弦反相交替摆动、小腿膝关节向后弯折、躯干上下轻微起伏。
  - 待机自然呼吸起伏、开火后坐力胸腔后仰抖动、阵亡后仰倒地骨骼解体坍塌。
- **精确 Hitbox 分区与伤害计算**：
  - 独立挂载 Hitbox：头部 (Head, 4x 爆头致命伤)、胸部 (Chest, 1.0x)、腹部 (Stomach, 1.1x)、手臂 (Arms, 0.8x)、腿部 (Legs, 0.75x)。
  - 护甲减伤系统（有防弹衣时根据各武器的甲穿比例吸收伤害并消耗 AP）。

### 3. 武器库与射击手感
- **AK-47**：36 身体伤害，爆头 144（单发一枪秒杀），射速 600 RPM，弹匣 30/90，后坐力剧烈（准星扩散大 + 枪口剧烈上扬）。
- **M4A4**：31 身体伤害，射速 666 RPM，弹匣 30/90，后坐力平稳易控，恢复速度快。
- **AWP 狙击枪**：115 身体伤害（一枪毙命），爆头 460，射速 40 RPM。**鼠标右键开镜**：3D 摄像机 FOV 从 75° 骤降至 20° 望远放大，全屏覆盖 2D 狙击镜刻度暗角遮罩。
- **手枪系列**：
  - **Glock-18**：T 默认手枪，28 伤害，20 发弹匣，点射迅速。
  - **USP-S**：CT 默认消音手枪，35 伤害，12 发弹匣，弹道极稳，枪声低沉干脆。
  - **Desert Eagle (沙鹰)**：53 伤害，爆头 212（一枪爆头必杀），7 发小弹匣，巨大后坐力。
- **战术近战刀 (Knife)**：近距离挥砍 (55 伤害) 与背刺判定。
- **C4 炸弹包**：程序化炸药块、绑带、数字化倒计时键盘与红色呼吸警报灯。

### 4. 手枪局机制与武器购买系统
- **手枪局开局**：第一回合为标准 CS 手枪局形态（全员仅配默认手枪 Glock/USP、无主武器、标配防弹衣）。
- **军火库购买面板 [按 B 键]**：随时呼出军火库菜单，查看 AK47、M4A4、AWP、沙鹰等详细数值属性并一键选装，或一键重置为经典手枪局模式。

### 5. C4 炸弹与回合胜负逻辑
- 回合开始时，C4 随机分配给 1 名 T（如果是玩家所选阵营则交予玩家）。
- **持包者阵亡**：C4 作为 3D 实体掉落于地面，任何存活的 T 走近 (2米内) 自动捡起。
- **下包**：持包 T 在 A 包点或 B 包点范围内，长按 [E] 键 3.2 秒安放，HUD 实时显示下包进度条并伴随按键音效。
- **倒计时与爆炸**：安放后进入 40 秒倒计时，随着时间减少蜂鸣声频率不断加快。倒计时归零触发巨大爆炸冲击波与音效，全图杀伤判定，T 方胜。
- **拆包**：CT 走近安放好的 C4 长按 [E] 键 5.0 秒完成拆除。拆除成功 CT 方胜。
- **队伍团灭判定**：未下包前击杀对方全员获胜。
- **阵亡接管 (Bot Takeover)**：玩家不幸阵亡后自动切换到存活队友的观察视角，**按 [E] 键可直接接管操控该队友 Bot** 继续战斗！

### 6. 5v5 智能 AI 战场
- 全场 10 人（1 玩家 + 4 AI 队友 vs 5 AI 敌人）。
- **A* 路径规划图 (Waypoint Graph)**：覆盖整个 Dust2 核心路线（A大、中路、小道、B洞、双包点、CT/T家），确保 AI 战术推进行走不卡墙。
- **视线感知与射线穿透检测 (Line of Sight)**：AI 拥有 120° 视野锥体与 80米视距，射线穿过墙体会判定为被遮挡无法发现敌人。
- **战术状态机**：
  - `navigate`：向目标包点或防守点巡逻推进。
  - `combat`：发现敌人立即停下或左右战术横移 (strafe)，校正枪口瞄准，根据武器连发或点射，触发后坐力。
  - `plant`：带包 T 到达包点主动寻找掩体下包。
  - `defuse`：已下包后所有存活 CT 切换为回防包点并前往拆包。
  - `reload`：子弹耗尽时寻找掩体换弹。

### 7. 现代 CS 风格 HUD & 小地图
- **常驻小地图 (Radar)**：左上角以高对比度矢量轮廓渲染 Dust2 俯视平面图，实时标出玩家方向朝向锥、队友位置、被侦察到的敌人红点脉冲、以及 C4 炸弹位置与 A/B 包点。
- **动态十字准星**：开火扩散、命中敌人时弹出红色 X 准心命中反馈。
- **HP / AP 面板**：生命值与防弹衣数值与填充条。
- **动态弹药面板**：当前弹夹 / 备弹数，各武器槽位快捷键提示 (1, 2, 3, 5)。
- **实时击杀播报 (Killfeed)**：右上角滚动播报杀手阵营、武器图标、爆头标记与受害者。
- **回合顶部记分板**：CT 与 T 比分、双方存活人数点位、回合倒计时 / C4 爆炸倒计时。

### 8. Web Audio API 纯程序化声音合成
- 不使用任何外部音频文件，使用 Web Audio API 原生振荡器、白噪声发生器与双二阶滤波器合成：
  - **AK-47**：厚重次低频下坠 (170Hz -> 38Hz) + 1.4kHz 带通白噪声金属枪响。
  - **M4A4**：清脆干脆的突击步枪破空声与高通滤波紧凑尾音。
  - **AWP**：雷鸣般的重型狙击爆鸣、深沉超低音下坠与长尾回音。
  - **手枪 (Glock/USP/沙鹰)**：9mm 塑料感点射、USP 消音微声气流、沙鹰沉重轰鸣。
  - **刀刺**：破空挥击声与血肉劈砍声。
  - **换弹**：弹夹拔出、装入卡榫与拉栓机械声。
  - **脚步声**：移动时基于速度节奏的程序化低通泥土/混凝土踏步声。
  - **命中音效**：身体击中钝响、爆头特有的金属头盔清脆 "叮！" 响声。
  - **C4**：安放按键音、倒计时蜂鸣 (频率随时间加快)、剪线音、核爆级超重低音大爆炸。
  - **回合电台**：开局提示音与胜利和弦 Fanfare。

## 🚀 运行与操作指南

### 启动项目
```bash
npm install
npm run dev
```
在浏览器打开 `http://localhost:3001` (或终端显示的端口) 即可进入游戏。

### 操作按键

| 按键 | 功能 |
|---|---|
| **鼠标左键** | 开火 / 射击 (长按全自动扫射) |
| **鼠标右键** | AWP 狙击开镜 / 关镜 (20° FOV + 瞄准镜遮罩) |
| **W / A / S / D** | 前进 / 左移 / 后退 / 右移 |
| **空格键 (Space)** | 跳跃 |
| **Shift** | 静音慢走 |
| **Ctrl** | 蹲下 |
| **R** | 换弹匣 |
| **1 / 2 / 3 / 5** | 切换主武器 / 副武器 / 匕首 / C4 炸弹 |
| **E** | 拆除 C4 / 安放 C4 / 接管存活队友 Bot |
| **B** | 打开 / 关闭 武器军火库菜单 (Buy Menu) |
| **鼠标点击屏幕** | 锁定指针进入第一人称视角 |
| **Esc** | 释放鼠标指针 / 关闭菜单 |
