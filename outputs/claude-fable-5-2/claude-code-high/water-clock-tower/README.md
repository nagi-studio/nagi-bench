# 水运仪象台 · 30 秒 3D 物理科普短片

北宋苏颂、韩公廉于 1092 年建成的水力天文钟——这部短片用约 33 秒讲清它**怎样靠水驱动、按时报时**：

> 水（天池 → 平水壶，流量恒定）→ 受水壶渐满 → 压下格叉 → 天条拉动天衡 → 天关抬起 → 枢轮转过一格又被卡住
> → 木齿轮 → 天柱 → 浑象 / 浑仪同步转动 → 机轮拨牙触动木人：时初摇铃、时正敲钟、报时牌更换

## 运行

```bash
bun run build        # 产物在 dist/
```

`dist/index.html` 离线可用：既可以放到任意静态服务器，也可以直接双击用 `file://` 打开（构建产物是经典脚本，不依赖 ES module / 网络）。
影片自动播放；浏览器若拦截了自动出声，点击画面任意处即可开启声音并从头播放；片尾有“重播”按钮（或按 `R`）。

## 技术栈

- **three.js 0.180** 渲染，**Rapier 0.21（rapier3d-compat）** 刚体物理，**Vite 8** 构建；无任何模型、贴图、音频文件。
- 贴图（木纹、星图、报时牌文字）全部用 Canvas 在运行时绘制；配乐与音效全部用 **Web Audio API** 实时合成。

## 哪些是物理算出来的

仪象台的全部机械运动都来自 `src/sim.js` 里的刚体、关节与碰撞，没有 kinematic 刚体、马达、补间或直接写位姿：

| 环节 | 物理实现 |
| --- | --- |
| 水 | 每颗水珠是一个刚体小球，沿水槽滚下落进水斗；重量真实累积 |
| 受水壶 ×36 | 各自用转动关节铰接在枢轮上（可下垂 14°） |
| 格叉 · 枢衡 · 枢权 | 带配重的杠杆；水斗的销子压在叉尖上，够重才压得下去 |
| 天条 | 铰接在天衡上的吊杆，下端横档钩在枢衡压板之下（只拉不顶，相当于链条） |
| 天衡 · 天关 | 杠杆 + 挡齿，挡住枢轮辐端的销子；被拉起后枢轮在水重作用下转动，天关落回卡住下一格 |
| 齿轮传动 | 木齿（胶囊碰撞体）真实啮合：轮轴大齿轮 → 天柱下轮；天柱中轮 → 浑象赤道牙；天柱上轮 → 浑仪天运环 |
| 报时 | 天柱上的拨牙顶起木人手里的杠杆锤，越过后落锤；锤头碰到钟 / 铃的**碰撞事件**触发对应的合成音 |

镜头、字幕、标注、外壳的淡入淡出不属于机械运动，按影片时间驱动；标注的高亮与“咔嗒”“钟声”等音效则由物理事件触发。
物理固定 120 Hz 步进，影片时间与物理时间严格同步，因此每次播放的结果一致。

说明：水珠在平水壶出水口以恒定速率生成（这正是平水壶的作用），落入退水壶后回收；为了在 30 秒内看清因果链，
演示做了时间压缩（每“一格”约 2.8 秒、每格换一块时牌），齿数与传动比为示意，并非文物原始数据。

## 目录

```
index.html          首屏片名页（关键样式内联）
src/sim.js          物理模型（Rapier）
src/view.js         场景与材质，物理 → 画面同步
src/film.js         分镜、镜头、字幕、标注
src/audio.js        Web Audio 合成（拨弦配乐、水声、木件撞击、钟、铃）
src/main.js         启动与主循环
tools/              开发自检脚本（无头物理测试、齿轮干涉检查、定帧截图、实时放映检查等）
```

调试：`window.__film.seek(t)` 可暂停并精确跳到影片第 `t` 秒（物理仍逐步推进），`#perf` 输出启动与帧耗时。
