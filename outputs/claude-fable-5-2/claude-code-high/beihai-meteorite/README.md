# 陨石雨 — 体素短片（Three.js，354 秒）

改编自刘慈欣《三体Ⅱ·黑暗森林》中章北海购买陨石、制作陨石子弹并在同步轨道行刺的段落。
全部画面、模型、贴图、特效与声音都由代码在浏览器运行时生成；没有任何外部素材。

## 运行

```bash
bun run build      # 产出标准 Vite 构建：dist/index.html + dist/assets/
bun run dev        # 本地开发
```

打开 `dist/index.html`（经静态服务器），点击「播放」或底部传输条的 ▶。空格 播放/暂停，← → 跳转 5 秒。

依赖只有 `three@0.180.0`、`@agentbench/cinematic-player`、`@agentbench/voxel-kit`（均由平台离线提供），包管理器为 Bun。
构建参数直接写在 `package.json` 的脚本里（`--base=./`），没有 Vite 配置文件。

## 结构

| 路径 | 内容 |
| --- | --- |
| `src/timeline.ts` | 全片时间表（秒）：段落边界、每一声枪响、撞击时刻 |
| `src/cues/voice.ts` | **语音清单**：56 条 `VoiceCue`，七个字段 `id / kind / speaker / text / delivery / start / end`，字幕直接由它驱动 |
| `src/cues/sound.ts` | 224 条程序化音效 cue |
| `src/audio/synth.ts` | 48 个 Web Audio 合成器（振荡器、生成的噪声缓冲、滤波、延迟、生成的混响脉冲响应） |
| `src/cast/` | 角色贴图（身体表与服装表分离）、演员封装、道具；所有人物均由 voxel-kit `createFigure` 装配 |
| `src/sets/` | 五个场景：胡同院落、藏石老宅、模型车间、地下室、同步轨道 |
| `src/shots/` | 72 个镜头，每个镜头都是绝对时间的纯函数，任意跳转结果一致 |
| `src/film.ts` / `src/main.ts` | 装配 `CinematicPlayer`、`ThreeStage`、`WebAudioCueBus`、传输控件与屏幕叠层 |
| `tools/` | 仅供开发的无头检查工具，不进入构建产物 |

## 改编与导演取舍

- **结构**：冷开场（轨道上等日落的人）→ 四个月前的买石 → 无对白的制作蒙太奇 → 回到轨道 → 尾声。
  开场的悬念「他在等什么」贯穿全片，直到合影者把面罩调成透明才被回答。
- **删去**：太空电梯与舰队建设的背景论述、增援未来计划、陨石矿物学的铺陈、核桃大小的第一块石头、还价的细节。
- **保留并加重**：「茶杯也是陨石」、「对要送的人的尊重」、36 这个数字、试枪后「看不出加工痕迹」、十秒飞行、「陨石雨」这个词。
- **新增**：受害者一句「干了一辈子航天，头一回，在天上照相」；尾声回到藏石的老宅——广播里说「陨石雨」，
  柜中三个空着的石座，收藏者只听见了一个令他神往的词。
- **匹配剪辑**：地下室里包着牛肉的航天服面料 → 轨道上他身穿的航天服；被钻出孔洞的陨石 ↔ 布包上的弹洞。
- **视觉**：地球、太阳、空间站、陨石、道具全部是体素几何；暖色的地面世界（灯、茶、木）对冷的轨道（逆光剪影、日落的橙与深蓝）。

## 声音与物理

- 地面：院落、老宅座钟、车间电流声、取芯钻与切断砂轮、地下室滴水。地下室枪声 = 爆鸣 + 生成的混凝土小房间脉冲响应卷积 + 平行墙颤动回声 + 之后的耳鸣。
- 轨道：只有航天服内能听到的声音——呼吸、风扇、无线电、手套环与磁铁座经手臂传导的闷响。
  手枪击发只有经服体传导的低频闷震；第二个弹夹的远景（「暗黑背景上的一只萤火虫」）**完全无声**。
- 合影者一侧的镜头使用他们自己的通讯频道（静噪、警报、漏气嘶声），章北海的瞄准镜主观镜头里听不到这些。
- 心跳、上升音与和声铺底属于主观/配乐层，不是场景内声源。
- 没有合成任何人声；所有台词、独白、广播只以底部居中的 `【说话者】文本` 字幕出现，等待按 `id` 配音。

## 验证说明

开发机上没有可用的浏览器（`chromium-browser` 只是 snap 占位，联网下载被拒绝），因此**未能在真实浏览器中点击播放验收**。
替代做法：

- `bun run build` 与 `tsc --noEmit` 通过；
- `bun tools/check.ts`：用真实的 `CinematicPlayer` 以 30 fps 走完整条时间轴（无异常、相机矩阵有限），
  并让全部 224 条声音 cue 的工厂在一个严格的 Web Audio 模拟上运行（含从每个持续 cue 中段恢复）；
- `bun tools/preview.ts`：CPU 软光栅把真实场景图按镜头渲染成联络表，用于逐镜头检查构图、调度与曝光（无阴影、无 DOM 叠层）；
- `bun tools/smoke.ts`：在模拟的 DOM / WebGL2 / Web Audio 下加载 **构建产物** `dist/assets/*.js`，点击传输条的播放键、
  推进动画帧、暂停、拖动进度条跳转、再播放，并让 three.js 的真实 JS 渲染路径走完整条时间轴直到 `ended`（不编译 GLSL、不出像素）。

真实 WebGL 下的阴影、抗锯齿与屏幕叠层（瞄准镜、字幕、片名）未经肉眼确认。
