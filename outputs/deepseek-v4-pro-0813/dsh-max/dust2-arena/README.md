# Dust2 Arena —— 5v5 第一人称射击原型

**React 18 + TypeScript + three.js** 从零实现，浏览器直接运行。复刻 Dust2 核心区域（T 出生点 / CT 出生点 / A大 / A点 / 中门 / 猫道 / B洞 / B点），1 名玩家 + 4 名 AI 队友 vs 5 名 AI 敌人。

- **零外部资产**：地图、角色、武器全部程序化几何体；声音全部 Web Audio 合成。
- **第三方运行时依赖仅** `three` / `react` / `react-dom`。寻路（自建 A* 导航网格）、状态机、物理、渲染循环全部手写。

## 运行

```bash
npm install
npm run dev      # 打开 http://localhost:5173
```

生产构建：`npm run build && npm run preview`

### 回合规则（标准 CS 形态）

- **手枪局**：第 1 回合全员默认手枪（Glock / USP-S）+ 刀，无护甲、无主武器，禁止购买。
- **经济系统**：击杀 +$300，安包/拆包 +$300，胜 +$3250，负 +$1400 起（连败递增）。第 2 回合起冻结时间按 B 购买 AK-47 / M4A4 / AWP / 沙鹰 / 护甲+头盔；AI 按经济自动起枪。
- **C4**：每回合随机一名 T 携带；阵亡掉落、T 靠近自动拾取；在 A/B 点内按住开火 3 秒安放，35 秒倒计时（滴答加速）。CT 在炸弹旁按住 E（6 秒）拆除。
- **胜负**：T 清空 CT 或 C4 爆炸 → T 胜；CT 清空 T（未下包）或拆包成功 → CT 胜；时间耗尽 → 未下包 CT 胜 / 已下包 T 胜。先到 8 回合获胜。

### 武器手感差异

| 武器 | 伤害(胸) | 射速 | 特点 |
| --- | --- | --- | --- |
| AK-47 | 36 | 600 RPM | 后坐剧烈（视角上扬 + 准星扩散），T 专属 |
| M4A4 | 33 | 666 RPM | 后坐低、射速快，CT 专属 |
| AWP | 115 | 41 RPM | 单发致命（腿 0.75×），右键开镜，不开镜无准星 |
| Glock-18 / USP-S | 30 / 34 | 半自动 | 手枪局默认武器 |
| 沙漠之鹰 | 52 | 267 RPM | 高伤害小弹匣 |
| 匕首 | 40 / 65 | — | 近战，左键轻击 / 右键重击 |

命中判定按 **Hitbox 分区**（头 2.0× / 胸 1.0× / 腹 1.25× / 臂 1.0× / 腿 0.75×），爆头为身体两倍伤害；有护甲时伤害减半并消耗护甲耐久。**中门 / 长门 / B门 门体可被子弹穿过**（伤害 ×0.55 衰减），玩家无法穿过。

## AI（5v5 战场）

- 自建导航网格 + A* 寻路（坡道/台阶高度约束、视线校验），不卡墙、会爬猫道坡。
- 视野索敌：视线被墙/门挡住不可见；交火（横移、点射、距离控制）、听到枪声会侦查。
- 战术：T 推包（A 大/中门猫道、B 洞/中门分路），安包后占位防守；CT 分守 A/B/中，炸弹安放后全队回防、就近拆包。
- 阵亡后可切换队友视角，按 E 直接接管该 AI 继续战斗。

## 架构

```
src/
├── game/
│   ├── types.ts          全局类型/常量（Hitbox 倍率、物理/回合参数）
│   ├── config.ts         武器数据系统（单一数据源：伤害/射速/后坐/扩散/价格）
│   ├── map/dust2.ts      Dust2 程序化地图：区域定义 → 高度场 → 自动墙体/门体/箱子
│   ├── nav.ts            导航网格 + A*（纯 TS，无依赖）
│   ├── audio.ts          Web Audio 程序化音效（枪声/脚步/换弹/开镜/C4/爆炸…）
│   ├── input.ts          键鼠输入
│   ├── store.ts          HUD 状态存储（useSyncExternalStore 订阅）
│   ├── bots.ts           AI 状态机（freeze/goto/combat/plant/defuse/hold）
│   ├── engine.ts         核心引擎：渲染循环、物理(子步碰撞/跳跃/爬坡)、Hitbox 射线、
│   │                     回合状态机、经济、C4、观战接管、视角
│   └── render/           程序化渲染：地图网格合并、类人角色骨骼、第一人称武器、特效
├── ui/                   React HUD：准星/血甲/弹药/击杀播报/小地图/购买/记分板/开镜遮罩
└── App.tsx               引擎与 React 生命周期桥接
```

**渲染循环 ↔ 物理帧 ↔ React 状态**：引擎在 rAF 中按 dt 推进模拟（水平移动子步碰撞防穿墙），HUD 通过 `HudStore`（可变状态 + 引用替换）以 20Hz 同步到 React，小地图由 Canvas 2D 每帧直接从引擎快照绘制。
