# DUST2 · 程序化 5v5 第一人称射击原型

无外部素材（模型 / 贴图 / 音频）的浏览器 FPS 原型：React 18 + TypeScript + three.js 全程序化构建。
复刻 Dust2 核心区域：T 出生点、CT 出生点、A 大、A 点、中门（可穿透门体）、猫道、B 洞、B 点，全部连通并带真实碰撞。

## 运行

```bash
npm install
npm run dev     # 浏览器打开提示的地址即可游玩
npm run build   # 类型检查 + 生产构建
```

## 玩法与操作

- 进入后选择阵营（T / CT）与主武器（步枪 / AWP），点击「进入对战」锁定鼠标。
- 5v5：你 + 4 名 AI 队友 vs 5 名 AI 敌人。首回合为手枪局（T 格洛克 / CT USP），此后发放步枪（每队一名 AWP 狙击手，玩家可选）。
- T 方携带 C4 前往 A/B 点下包，爆炸即胜；CT 方阻止或拆除（按住 E）。

| 按键 | 功能 |
| --- | --- |
| WASD / Shift / 空格 | 移动 / 静步 / 跳 |
| 鼠标 | 视角（指针锁定）、左键射击 |
| R | 换弹 |
| 1 / 2 / 3 / 4 或滚轮 | 切枪（4 = C4，装备后按住左键下包） |
| 右键（AWP） | 三段开镜（3D 拉近 + 2D 遮罩） |
| E | 拆除 C4（CT） |
| F / 左键（阵亡时） | 接管队友 / 切换观战视角 |

## 系统

- **引擎与渲染分离**：`src/game/` 为纯逻辑（Node 可无头运行），`src/game/render.ts` 为 three.js 渲染层，`src/ui/` 为 HUD。
- **多层寻路网格**（0.9m 格、6 层高度）+ A*（二叉堆、跨层爬升物理校验、一次性预计算边表），路线链与卡住自恢复。
- **AABB 碰撞**：台阶登升（0.56m）、地面吸附、薄台阶盒。
- **武器系统**：AK-47 / M4A4 / AWP（右键开镜）/ Glock / USP / Deagle / 刀，扩散、后坐、换弹、切枪。
- **命中盒部位伤害**：头 ×2.0、胸、腹、手臂、腿，护甲减伤，穿门衰减。
- **C4**：携带 / 掉落 / 安放 / 拆除 / 爆炸，回合胜负与比分逻辑。
- **AI**：巡逻、视锥 + 视线感知、自动交战（站定射击 / 点射 / 压枪）、推点路线链、下包 / 拆包 / 守点。
- **程序化音效**：Web Audio 合成枪声、换弹、脚步、开镜、命中、下包、拆包、爆炸等。
- **HUD**：准星（扩散 / 命中标记）、血量护甲、弹药、击杀信息、小地图、开镜遮罩、观战面板。

## 无头验证

```bash
npm run test:map   # 53 项地图连通性 / 视线 / 物理检查
npm run sim        # 12 分钟 5v5 全自动仿真（回合 / 下包 / 爆炸统计）
```

## 架构

```
src/
  game/        纯逻辑引擎（无 DOM）：config / math / map / models / viewmodel / audio / engine / render
  ui/           React HUD 组件
  App.tsx      输入、主循环、事件->音效分发
  main.tsx     入口
scripts/
  test-map.ts  地图与寻路回归测试
  sim.ts       无头仿真
```
