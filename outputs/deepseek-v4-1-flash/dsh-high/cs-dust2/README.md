# Dust2 5v5 — Procedural FPS Prototype

一个可直接在浏览器运行的 **3D 第一人称射击原型**：复刻 Dust2 核心区域，进行 5v5 战术对战。
全部内容（地图、角色、武器、音效）都在代码里程序化生成，**不使用任何外部资产文件**。

技术栈：**Vite + React 18 + TypeScript + three.js**。运行时第三方库只有 `three` / `react` / `react-dom`；
寻路、状态机、物理、渲染循环均为自研实现。

---

## 快速开始

```bash
npm install
npm run dev
```

打开终端输出的地址（默认 <http://localhost:5173>），点击「开始对局」，浏览器会请求鼠标锁定。

其他命令：

```bash
npm run build     # 类型检查 + 生产构建
npm run typecheck # 仅类型检查
npm test          # 无头验证：角色/武器数据、地图连通性、完整对局模拟
```

## 已实现内容

### 地图（`src/world/`）
- 程序化网格布局，完整包含：**T 出生点、CT 出生点、A 大、A 点、中路、中门（可穿过）、猫道、B 洞、B 点**，
  以及 CT→A / CT→B / 中→B 等连接通道，全部连通。
- 墙体由「可行走格子的边界」自动合并生成，门洞天然成型；中门额外带有可见的双开门框。
- 所有墙体 / 箱子都有 AABB 碰撞体，玩家和 AI 都无法穿墙；箱子可跳上。
- `scripts/validateMap.ts` 会自动验证每个区域存在、关键路线可达、中门可穿过、出生点不在实体里。

### 角色（`src/entities/character.ts`）
- 纯几何体拼装的类人角色：**独立的头、躯干、双臂（肩部枢轴）、双腿（髋部枢轴）**，共 12 个部件，
  带行走摆臂摆腿、下蹲、持枪姿态与武器挂点。
- CT 为蓝色制服 + 头盔，T 为沙色制服 + 帽子，一眼可辨。
- Hitbox 分区：**头 / 胸 / 腹 / 手臂 / 腿**，伤害倍率不同，**爆头为身体两倍**；有护甲时按护甲减伤，
  头盔额外保护头部。

### 武器（`src/weapons/`）
数据驱动的武器系统，支持主武器 / 副武器 / 近战切换，每把枪都有第一人称程序化模型：

| 武器 | 特点 |
| --- | --- |
| AK-47 | 高伤害、后坐力剧烈（准星扩散 + 视角上抬明显） |
| M4A4 | 中等伤害、后坐力低、射速高 |
| AWP | 单发致命、射速极低、右键开镜（3D FOV + 2D 遮罩） |
| Glock / USP | T / CT 默认手枪，伤害低于步枪 |
| 沙漠之鹰 | 伤害介于手枪与步枪之间、弹匣小 |
| 刀 | 近战，背刺双倍伤害 |

包含后坐力弹簧回复、移动/跳跃/下蹲影响精度、换弹动画、弹道曳光与枪口闪光。

### 回合与 C4（`src/game/game.ts`）
- **手枪局**：第 1 回合全员只有默认手枪、无主武器、无护甲；之后回合自动配发步枪 / 狙击枪与护甲头盔。
- C4 随机交给一名 T；持包者阵亡后掉落，其他 T 靠近即可拾取。
- 持包 T 在 A / B 点内按 `E` 安放，随后进入 40 秒倒计时；CT 站在 C4 旁按 `E` 持续拆除。
- 胜负判定：T 全歼 CT / C4 爆炸 → T 胜；CT 全歼 T（未下包）/ 成功拆包 / 时间耗尽 → CT 胜。

### AI（`src/ai/`, `src/game/bot.ts`）
- 10 人同场：1 名玩家 + 4 名 AI 队友（T）对抗 5 名 AI（CT）。
- **网格 A\*** 寻路 + 路径平滑 + 卡墙自恢复，箱子区域在导航网格中被屏蔽，不会撞箱卡死。
- **视野索敌**：距离 + 视角 FOV + 射线遮挡（被墙挡住看不见），命中后有反应延迟与瞄准误差。
- 状态机：巡逻 / 推进 / 交战 / 防守 / 下包 / 拆包 / 搜索，会在交火时继续推进目标点；
  持包进点后强制下包，CT 到位后强制拆包。
- 玩家阵亡后可接管任意存活队友继续操控。

### HUD / UI（`src/ui/`）
- 十字准星（随扩散动态张合）、生命 / 护甲、动态弹药面板（开火递减、换弹恢复）、
  右上角击杀播报、顶部比分 / 回合计时 / 存活人数、C4 计时。
- **小地图**：常驻显示 Dust2 俯视轮廓、炸弹点、自己 / 队友 / 被己方看到的敌人 / C4 位置。
- AWP 开镜 2D 遮罩、受伤红屏、命中反馈、暂停 / 开始菜单。

### 音效（`src/audio/audio.ts`）
全部用 **Web Audio API 程序化合成**，无音频文件：AK / M4 / AWP / 手枪 / 沙鹰区分开火声、
换弹声、脚步、跳跃、AWP 开镜、命中（区分头部 / 护甲）、C4 安放 / 拆除 / 爆炸、击杀提示、回合胜利音。

## 架构

```
src/
  main.tsx / App.tsx          入口与 React 生命周期，桥接引擎与 HUD
  engine/
    constants.ts              物理 / 回合 / 地图常量
    input.ts                  键鼠状态、指针锁定、每帧输入快照
  core/math.ts                数学工具
  world/
    mapLayout.ts              网格地图数据、自动墙体生成、碰撞体、出生点 / 炸弹点
    mapMesh.ts                three.js 场景几何（实例化墙体、箱子、炸弹点贴花、中门、灯光）
  physics/collision.ts        AABB 射线、分轴移动解算、地面检测、视线检测
  entities/character.ts       类人角色骨架、动画、队伍配色、hitbox
  weapons/
    weapons.ts                武器数据表、伤害衰减、区域倍率
    viewModel.ts              第一人称模型与后坐 / 换弹 / 摆动动画
  ai/navigation.ts            导航网格 + A* + 路径平滑
  game/
    types.ts                  共享类型与 HUD 状态
    actor.ts                  角色实体：物理、武器运行时状态
    bot.ts                    AI 状态机
    game.ts                   全局状态引擎：渲染循环、物理帧、回合、C4、命中判定、HUD 发布
  ui/
    Hud.tsx / Minimap.tsx / Menus.tsx
```

渲染循环采用固定步长（64Hz）累加器驱动物理与 AI，渲染与 React 状态（15Hz 快照）解耦。

## 验证脚本

`npm test` 会依次运行：

1. `validateSystems.ts` — 角色部件、hitbox 分区、武器数据（伤害 / 射速 / 后坐力 / 开镜 / 爆头倍率）。
2. `validateMap.ts` — 全部区域存在、9 条关键路线连通、中门可穿过、箱子不在墙里、出生点合法。
3. `sim.ts` — 无头运行真实游戏逻辑 10 分钟，验证回合推进、AI 下包、击杀、换弹、手枪局、玩家接管均无异常。

`tsx scripts/renderMap.ts` 可把导航网格导出为 `map-layout.png` 便于查看布局。
