# 北海 · 陨石 / The Meteorite

一部完全由代码生成、在浏览器中实时运行的 **Three.js 程序化 3D 电影**，改编自《三体 Ⅱ·黑暗森林》中
章北海用陨石子弹刺杀三位“老航天”、从而把人类推上无工质聚变辐射驱动的段落。

全片总时长 **344 秒**（含片头与片尾，硬上限 360 秒）。所有几何、贴图、灯光、特效与声音都在运行时
用代码生成，不使用任何外部模型、贴图、字体或 CDN 资源；除 `three` 外没有第三方运行时依赖。

```
bun install
bun run dev        # 本地预览
bun run build      # tsc --noEmit && vite build -> dist/
bun run preview    # 预览构建产物
bun run check      # 无头自检：时间轴 / 语音清单 / 音频引用 / 全片播放不抛错
bun run render     # 无浏览器 CPU 软渲染若干帧，用于构图与布光自检
```

---

## 1. 导演阐述

原文是素材，不是剧本。影片做了如下取舍与重组：

- **压缩**了长达三年的技术路线争论，只用一场评审会、一次走廊敬礼和一段内心独白交代。
- **保留并放大**了三个核心意象：**陨石**（宇宙的偶然与不可追溯）、**子弹**（把偶然做成工具）、
  **蓝色的聚变火焰**（用血换来的未来）。
- **删去**了法医与调查的全部过程细节，只留下报告里的一句话——“一起罕见的陨石雨坠落事故”。
- **非线性**：第五幕把“独自面对玻璃”与“试验台点火”并置，让记忆闪回与推进器轰鸣互相切割，
  完成从“杀人者”到“人类选择”的意义翻转。

视觉语言是严格的体素/方块语言：人物、道具、建筑全部由方块构成；但用电影化的构图、色彩与光影
建立自己的体系——**冷蓝的机构空间**（评审会、走廊、法医室、模型车间）与**暖橙的工坊/市场**、
**近乎单色的地下室**、以及**蓝白色的聚变点火**形成一条清晰的色彩弧线。

## 3. 语音清单（字幕的唯一来源）

所有对白、旁白、内心独白、广播与通讯共 **29 条**，集中保存在 `src/film/cues.ts` 的 `VOICE_CUES`
数组中。每条严格只有七个字段：

```ts
{ id, kind, speaker, text, delivery, start, end }
```

- `kind` ∈ `dialogue | voiceover | narration | broadcast | radio`
- 字幕由这份清单直接驱动，格式固定为画面底部居中的 **`【说话者】文本`**（见 `src/style.css` 的
  `#subtitle` 与 `src/film/director.ts` 的 `updateSubtitle`）。
- 项目**不合成任何人声**；所有待配音内容只以字幕呈现，后期可按 `id` 逐条接入录音。
- 纯视觉段落（如三声枪响、点火）刻意不加字幕，用沉默和音效承担。

示例：

| id | kind | speaker | start–end | text |
|---|---|---|---|---|
| v04 | voiceover | 章北海（内心） | 46.6–55.4 | 工质驱动的舰队，在黑暗森林里，连一次真正的加速都撑不过去。 |
| v10 | dialogue | 章北海 | 110.6–114.4 | 人。 |
| v19 | dialogue | 调查员 | 200.6–212.0 | 没有膛线，没有可追溯的弹头……一起罕见的陨石雨坠落事故。 |

## 4. 声音设计

声音由 **平台离线 CC0 采样库** + **Web Audio API 程序化合成**两层叠加，全部通过
`src/lib/audio.ts` 的 `AudioEngine` 调度：

- **枪声**：合成的高频爆裂 + 低频冲击 + 采样弹体，再送入按环境切换的程序化卷积混响。
  地下室湿声 0.62，真空 0.02——**真空中不传播外部枪声**，只用沉默与主观闷震表现。
- **环境**：荧光灯嗡鸣、车床循环、市场人声底噪、航天服呼吸、无线电静电、倒计时蜂鸣、
  推进器轰鸣与低频地震感，均由采样与噪声/振荡器合成。
- **混音**：主压缩器 + 每帧事件触发，音画同步误差不超过一帧；暂停/跳转时会重新布防。

## 5. 技术实现

```
src/
  main.ts              浏览器引导：渲染器、后处理、音频、输入、主循环
  style.css            电影画幅（遮幅、暗角、颗粒、字幕、片头/片尾卡）
  lib/
    rng.ts             确定性随机与缓动
    textures.ts        程序化 DataTexture（混凝土/金属/陨铁流纹/木纹/织物/星场/点精灵）
    materials.ts       材质库与色彩脚本
    voxel.ts           方块构建套件（按世界尺寸平铺 UV、静态合并）
    cameraRig.ts       关键帧机位、手持漂移、冲击震动
    audio.ts           Web Audio 声音引擎（采样 + 合成 + 卷积混响）
    postfx.ts          EffectComposer：泛光 + 胶片分级（色差/颗粒/暗角）
  art/
    characters.ts      体素人物（可摆姿、行走、瞄准、敬礼、倒下）与手枪/公文包道具
  sets/
    shared.ts          房间、灯管、吊灯、尘埃、桌椅等通用构件
    act1..act5.ts      十个体素场景
  film/
    cues.ts            语音清单（唯一字幕来源）
    soundtrack.ts      音效清单
    shots.ts           分镜与机位关键帧（344 秒）
    director.ts        时间轴调度、字幕、片头/片尾、环境分级
    world.ts           场景/演员/特效装配
    fx.ts              火花、烟雾、碎屑、闪光、聚变火焰（对象池）
tools/
  check.ts             无头自检（时间轴、清单、音频引用、全片播放）
  render.ts            CPU 软渲染预览（无浏览器时用于构图/布光自检）
  montage.ts           把预览帧拼成接触表
```

- **渲染**：`WebGLRenderer` + ACES 色调映射 + PCF 软阴影 + `UnrealBloomPass`。
- **性能**：单帧可见三角面约 2–3.5k（静态场景合并、共享材质），十套场景分置在互不可见的世界坐标，
  同一时刻只点亮当前场景。
- **稳健性**：音频加载失败、`AudioContext` 不可用、或用户未交互时，画面仍会自动播放；
  空格暂停、← → 跳转、R 重播、M 静音、F 全屏、H 显示时间码。

## 6. 自检

`bun run check` 会构建真实世界、用真实导演逻辑以 30fps 跑完整片，并断言：

- 总时长 ≤ 360 秒，镜头首尾相接且无空隙；
- 每条语音 cue 恰好七个字段、无重叠、落在影片区间内，字幕以 `【` 开头；
- 所有被引用的采样文件都存在；
- 全片 10,320 帧播放无异常抛出。

`bun run render` 在无浏览器环境下用 CPU 软渲染输出关键帧，用于检查构图、走位与布光。
（软渲染不做阴影与泛光，成片在 WebGL 中会有更强的体积感与高光。）
