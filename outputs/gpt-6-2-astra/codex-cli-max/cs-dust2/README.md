# DUSTLINE · Dust II

基于 React 18、TypeScript 和 three.js 的本地第一人称爆破对局。一名玩家与四名 AI 队友对抗五名 AI 对手。

## 启动

项目已在 Node.js 22.23 环境验证。在项目目录运行以下命令，打开 Vite 输出的本地地址。

```sh
npm install
npm run dev
```

```sh
npm run build
npm run preview
```

首次进入会显示 T 出生点和当前配装。点击 **进入战局** 或按 **Enter** 开始。设置中可选择 T 或 CT 阵营。准备区的武器卡可试配和切换武器。

## 对局

- 默认采用步枪局，右下角的 **步枪局开局** 按钮可切换为 **手枪局**。手枪首轮全员仅配阵营默认手枪、匕首，护甲为零。第二回合恢复完整配装。
- 路线按经典区域的连接关系程序化重建。T 侧可走 A 大门与 A 大道，或从中路转猫道进入 A 点。B 洞连接 T 侧通道、中路与 B 点。CT 出生点连通中门、A 坡道与 B 门。
- 每轮 115 秒。T 持包者在爆破点静止交互 3 秒即可安放。C4 在 40 秒后引爆，CT 靠近装置并静止交互 5 秒可拆除。
- 持包者阵亡后掉包，T 靠近即可拾取。安放前全歼敌队即可获胜。安放后，CT 仍须拆包。未安放时超时由 CT 获胜。
- 玩家阵亡后自动观战存活队友，可切换视角或接管该队友。每局最多 24 回合，先获 13 分获胜。
- 小地图以浅色箭头表示自身，青色表示队友，橙色菱形表示 C4。红点来自队伍视野，短暂保留敌人的最后可见位置。

## 操作

| 操作                     | 按键                     |
| ------------------------ | ------------------------ |
| 移动、静步、跳跃         | WASD、Shift、空格        |
| 转向                     | 鼠标，方向键亦可调整视角 |
| 射击、AWP 开镜           | 左键、右键               |
| 主武器、副武器、近战     | 1、2、3 或滚轮           |
| 换弹                     | R                        |
| 安放或拆除 C4            | 靠近目标长按 E，保持静止 |
| 从附近持包队友接包、丢包 | E、G                     |
| 观战时切换、接管队友     | Q、Enter                 |
| 计分板、指南             | 长按 Tab、H              |
| 暂停及释放鼠标           | Esc                      |

支持 WebGL 2、Web Audio 和指针锁定的桌面浏览器可获得完整操作体验。指针锁定受限时可在画布内移动鼠标或使用方向键。触屏设备提供方向按钮、拖动视角和交互键。

## 实现

| 模块                                            | 职责                                                                         |
| ----------------------------------------------- | ---------------------------------------------------------------------------- |
| `src/game/map.ts`                               | 区域、地形高度、建筑和箱体碰撞、带旋转的门板、视线检测、八方向 A* 与路径平滑 |
| `src/game/match.ts`                             | 固定步长模拟、角色运动、战斗、分区命中、AI 决策、C4 状态、回合和接管         |
| `src/game/weapons.ts`                           | 武器属性、弹量、后坐力、射速和分区倍率                                       |
| `src/game/arena.ts`                             | 输入、固定物理步长累加器、动画、双相机渲染、状态发布和资源释放               |
| `src/game/world.ts`、`models.ts`、`geometry.ts` | 程序化街区、材质、植被、角色、持枪手臂、武器和静态几何合批                   |
| `src/game/audio.ts`                             | 振荡器与噪声经滤波和包络合成音效，按距离及方向混音                           |
| `src/ui/`、`src/App.tsx`                        | 雷达、HUD、装备、设置、计分板和操作指南                                      |

物理模拟以 60 Hz 推进，渲染由 requestAnimationFrame 驱动。对局引擎约每 82 毫秒向 React 发布独立快照，换装、阵亡和回合结算等事件立即刷新。页面卸载时移除输入监听并释放 WebGL 和音频资源。

场景几何、贴图和界面图形均由代码生成。运行时依赖仅有 three、react 和 react-dom。

## 回归验证

运行 `npm test` 可验证导航连通性、门板碰撞、可见性、手枪首局、命中分区、换弹、死亡接管、C4 掉落与回收、中断交互、回合胜负，以及 AI 在两处爆破点的自主安放。测试使用固定随机种子和独立的对局实例。
