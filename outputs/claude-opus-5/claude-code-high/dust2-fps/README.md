# de_dust2 — 5v5 FPS 原型

浏览器里直接跑的 3D 第一人称射击原型：**React 18 + TypeScript + three.js**，复刻 Dust2 核心区域的 5v5 对战（1 名玩家 + 4 名 AI 队友 vs 5 名 AI 敌人），含完整的回合制 / C4 / 经济 / 购买流程。

**没有任何外部素材**：地图、人物、武器全部用几何体在代码里程序化生成，所有音效用 Web Audio API 实时合成，寻路 / 状态机 / 物理 / 渲染循环全部自己实现。第三方依赖只有 `three` / `react` / `react-dom`。

## 运行

```bash
npm install
npm run dev          # http://localhost:5173
```

其他脚本：

```bash
npm run build        # tsc -b && vite build
npm run typecheck    # tsc --noEmit
npm test             # 全部离线测试（单元 + 地图 + 寻路 + 长时间对局压测）
npm run map          # 在终端打印地图俯视 ASCII 图
```

## 操作

| 按键 | 功能 | 按键 | 功能 |
| --- | --- | --- | --- |
| `WASD` | 移动 | `1 / 2 / 3` | 主武器 / 手枪 / 刀 |
| `空格` | 跳跃（空中按住蹲可上箱子） | `滚轮` | 切换武器 |
| `Ctrl` / `C` | 蹲下 | `E`（按住） | 安放 / 拆除 C4 |
| `Shift` | 静步（无脚步声） | `B` | 购买菜单（准备阶段） |
| `鼠标左键` | 开火 | `Tab` | 记分板 |
| `鼠标右键` | AWP 开镜 | `F` | 阵亡后接管队友 |
| `R` | 换弹 | `M` / `Esc` | 静音 / 释放鼠标 |

点击画面锁定鼠标开始游戏。阵亡后自动进入队友视角，`空格`/`左键`切换观战目标，`F` 直接接管该队友继续战斗。

## 地图

按 Dust2 实际走位搭建，区域之间的连通关系与原图一致（`npm run map` 可查看）：

```
                  ┌──────── CT 出生点 ────────┐
     B 点          │                          │        A 点
      │            └── CT 中路 ── A 大通道 ────┘         │
   B 通道       B 门     │                          猫道 / A 小道
      │            └─────┤  中路（含中门）              │
   上层管道                │                        A 大（长廊）
      └────────────── T 出生点 ────── 长廊门 ──────────┘
```

包含：T 出生点、CT 出生点、A 大（长廊 + 长廊门）、A 点（抬高 1.2 m 的平台 + 箱子）、中路（含可穿过的中门门体）、猫道、B 洞（上层管道 + 拐角）、B 点（抬高 0.5 m + 平台箱 + 车），以及 A 大道、CT 中路、B 门、坑位等连接区域。

地图以 **1 m 的实心/空心网格**描述（112×108 格，4083 个可行走格）。这样做一次性拿到三样东西：

* **不漏气的碰撞** —— 墙体由“非可行走格”隐式构成，不存在手摆墙之间的缝隙；
* **免费的导航网格** —— 每个可行走格就是 A\* 的一个节点；
* **精确的射线** —— 子弹与视线用 DDA 在网格上步进求交。

渲染时用贪心合并（greedy meshing）把地面和墙面合并成矩形，塞进两个 `InstancedMesh`，整张图只有 2 个 draw call。

## 架构

```
src/
  core/        math.ts (Vec3/角度/PRNG) · types.ts · events.ts (类型化事件总线)
  map/         grid.ts (网格/DDA/贪心合并) · world.ts (碰撞+射线+区域)
               dust2.ts (关卡数据) · nav.ts (A* + 路径平滑)
  game/        weapons.ts (武器数据表) · hitbox.ts (分区判定) · actor.ts
               physics.ts (移动/碰撞) · combat.ts (射击/伤害) · ai.ts (行为状态机)
               engine.ts (回合状态机 / C4 / 经济 / 快照)
  render/      renderer.ts · mapMesh.ts · character.ts (人形骨架)
               viewmodel.ts (第一人称手持) · weaponModel.ts · effects.ts · materials.ts
  audio/       audio.ts (纯合成音效)
  input/       input.ts (键鼠 + 指针锁定)
  ui/          HUD · Minimap · Killfeed · Scoreboard · BuyMenu · ScopeOverlay · StartScreen
  hooks/       useEngineSnapshot.ts
tools/         离线测试与地图工具（Node 原生 TS 剥离，无需构建）
```

### 三条时间线的同步

| 时间线 | 频率 | 负责 |
| --- | --- | --- |
| **模拟** `GameEngine.step()` | 固定 64 Hz（带累加器补帧） | 唯一的游戏真相：移动、命中、AI、回合、C4 |
| **渲染** `GameRenderer.render()` | rAF（显示器刷新率） | 只读取引擎状态摆放物体，从不修改状态 |
| **React HUD** | 20 Hz 快照 | `useSyncExternalStore` 订阅不可变快照，事件（击杀 / 下包）时立即推送 |

关键点：模拟层完全不 import three / React / DOM，只通过 `EventBus` 抛出 `shot / hit / death / bombPlanted …` 事件，渲染与音频作为订阅者响应。**因此整套游戏逻辑可以在 Node 里无头运行**——`tools/` 里的测试就是这么跑的。

小地图不走 React state：它直接读引擎状态在 canvas 上重绘，避免每帧触发组件树 diff。

## 系统实现要点

**武器系统**（`weapons.ts` 数据驱动，新增武器只需加一条记录）

| | 伤害(胸) | 爆头 | RPM | 弹匣 | 手感 |
| --- | --- | --- | --- | --- | --- |
| AK-47 | 50 | 100 | 600 | 30 | 后坐力剧烈，准星扩散大，一枪爆头 |
| M4A4 | 33 | 66 | 666 | 30 | 后坐力低、射速高 |
| AWP | 115 | 230 | 41 | 10 | 单发致命，右键开镜（FOV 90°→26° + 2D 镜片遮罩），移速最慢 |
| 沙鹰 | 60 | 120 | 267 | 7 | 介于步枪与手枪之间，弹匣小 |
| USP-S / Glock | 32 / 26 | 64 / 52 | 352 / 400 | 12 / 20 | CT / T 手枪局默认 |
| 刀 | 55 | — | — | — | 背刺 ×3.2 |

命中按 **Hitbox 分区**：头 ×2.0、腹 ×1.25、胸 ×1.0、手臂 ×0.8、腿 ×0.7（爆头恰好是身体两倍，见 `tools/unit.ts` 的断言）。有护甲时按武器穿透率折算并消耗护甲值，头盔单独影响爆头。开火同时累计弹道扩散与视角上扬，停火后按武器各自的恢复速度回正；准星缺口实时反映当前扩散。

**AI**（`ai.ts`）：感知（120° 视野 + 视线遮挡射线 + 枪声听觉）→ 决策（`advance / engage / hunt / hold / plant / defuse / rotate`）→ 执行（A\* 寻路 + 卡墙自恢复、按距离控制点射节奏、压枪停顿、依技能设定反应时间与瞄准误差）。回合开始分配角色：进攻方集体推同一个点，防守方 2A / 2B / 1 游走；下包后攻方转为守包、守方全体回防拆包。

**回合与 C4**：准备阶段 8 s（可购买）→ 115 s 回合 → 结算 5 s。C4 回合初交给某个 T，持包者阵亡后掉落并可被其他 T 捡起；在 A/B 点范围内按住 `E` 安放 3.2 s，引信 40 s（滴答声随剩余时间加快）；CT 站在包上按住 `E` 拆除 10 s（有拆弹器 5 s）。胜负：清空对方 / 爆炸 / 拆包 / 时间耗尽，并结算击杀奖金与连败补偿。第 1、13 回合为**手枪局**（只有默认手枪、无护甲），主菜单也可选择“纯手枪局”模式。

**音效**：全部由噪声缓冲 + 双二阶滤波器 + 振荡器包络合成，武器的 `sfx`（音量 / 频率 / 长度 / 低频量）写在武器表里，所以 AK 沉、M4 脆、AWP 轰、手枪短促各不相同；另有换弹三段机械声、脚步、开镜咔哒、命中反馈、击杀提示、C4 安放 / 滴答 / 拆除 / 爆炸。世界音源按距离衰减并根据听者朝向做立体声声像。

## 离线测试

因为模拟层不依赖浏览器，所有玩法逻辑都能用 Node 原生的 TypeScript 剥离直接跑（无需编译）：

```bash
npm test
```

* `tools/unit.ts` — 74 项断言：伤害模型（含“爆头 = 身体 2 倍”）、护甲与头盔、hitbox 分区、视线遮挡、武器手感差异、换弹、移动与碰撞（撞墙 / 上坡 / 蹲跳上箱）、回合规则与经济、C4 安放 / 掉落 / 拾取 / 拆除 / 爆炸、阵亡接管、手枪局。
* `tools/mapcheck.ts` — 地图连通性洪泛：全部 4083 个可行走格互相可达，各关键区域与出生点、锚点均在可行走区域内。
* `tools/navcheck.ts` — 关键路线寻路 + 300 组随机点对全部可达。
* `tools/verify.ts` — 以 64 Hz 跑完整 10 人对局（默认 600 s ≈ 11 个回合），逐帧校验：无人穿墙、无人越界、无 NaN、无长时间卡死，并统计击杀 / 下包 / 拆包等事件。

## 已知取舍

* 墙体为轴对齐的 1 m 方块，Dust2 的斜角墙用直角近似；空间比例与走位关系还原，但不是逐单位复刻。
* 玩家回合开始会按余额自动配一把默认武器，再用购买菜单覆盖；没有做完整的经济博弈（存钱局 / 换边 / 加时）。
* 没有投掷物（烟 / 闪 / 火）与穿透（子弹被墙完全挡住）。
* 队友之间不会互相误伤，子弹直接穿过队友。
