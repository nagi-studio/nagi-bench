# DUST2 — 浏览器 3D 第一人称射击原型

用 **React 18 + TypeScript + three.js** 从零实现的 5v5 FPS 原型：复刻 de_dust2 核心区域，1 名玩家 + 4 名 AI 队友对抗 5 名 AI 敌人，完整的 C4 下包 / 拆包 / 回合结算流程。

**不使用任何外部资产文件**：地图、角色、武器全部由代码用几何体程序化生成，音效全部由 Web Audio API 程序化合成。第三方依赖只有 `three` / `react` / `react-dom`——寻路（A*）、状态机、碰撞与物理、渲染循环、音频合成全部自行实现。

---

## 快速开始

```bash
npm install
npm run dev        # 打开 http://localhost:5173 即可游玩
```

其它脚本：

```bash
npm test           # 无头测试：静态检查 + 地图/寻路 + 玩法模拟 + 渲染层（100 项断言）
npm run typecheck  # tsc --noEmit
npm run build      # 生产构建
```

> 环境要求：Node ≥ 20.19（Vite）。`npm test` 直接用 Node 原生 TypeScript 支持运行 `.ts`，需要 **Node ≥ 22.18**。

## 架构

三条循环各跑各的频率，通过一条**事件队列**和一份**只读快照**解耦：

```
                 ┌──────────────── requestAnimationFrame (显示帧率) ─────────────────┐
                 │                                                                  │
InputController ─┴─▶ GameWorld.update(dt)                                            │
  DOM 事件           └─ 固定 64Hz tick × N ─▶ AI 状态机 → 移动/物理 → 战斗 → C4 → 回合  │
                                              │                                      │
                                              ├─ events[] ─▶ GameRenderer.sync()  ───┤─▶ WebGL
                                              ├─ events[] ─▶ AudioEngine.consume()   │
                                              └─ events[] ─▶ HudStore (30Hz 快照) ───┴─▶ React
                                                                    │
                                                     useSyncExternalStore → HUD 组件
```

要点：

- **模拟层完全不依赖 three.js 与 React**（`src/core`、`src/game`）。它自带一套 `Vec3` 数学层，因此可以直接在 Node 里无头运行整场比赛——这正是 `npm test` 能真跑 30 个回合做断言的原因。这条边界由 `tools/statictest.ts` 自动守卫。
- **固定时间步长**：模拟恒定 64 Hz（与 CS 服务器一致），显示帧率无关；鼠标视角每帧应用一次以保证手感。
- **React 不参与热循环**：HUD 只在 30 Hz 的快照变化时重渲染，`useSyncExternalStore` 保证一致性；准星、血量、弹药都来自这份不可变快照。
- **单一数据源**：墙体、导航网格、小地图、渲染网格全部由同一份 `dust2.ts` 楼层平面推导，所以「看到的」和「撞到的」永远一致。

## 1. 地图

`src/game/map/dust2.ts` 用**可行走扇区**（带高度、可带坡度的矩形）描述楼层平面，其余全部推导：

- **墙体**：沿每个扇区边界逐格检测，外侧不可行走处自动生成墙盒并合并；开口处不会被墙角补偿挤窄（这个 bug 被 `maptest.ts` 抓到过）。
- **台阶/落差**：相邻扇区高差过大时自动生成挡墙，因此可以从猫道跳下中路，但不能从中路爬上猫道。
- **封闭性**：测试从 500 个采样点向 16 个方向发射射线，验证地图没有漏洞。

包含区域：T 出生点、T 斜坡、T 中路、**中门（两扇实体门 + 可穿过的中间开口）**、中路、CT 中路、CT 出生点、**猫道（含上坡）**、A 小道、**A 点**、A 坑（含台阶出口）、长廊拐角、**A 大（Long）**、长廊门、**B 洞（上/下通道）**、B 洞出口、**B 点**、B 门通道。

`maptest.ts` 会对 24 个战术点做 552 条全连通性 A* 校验，并单独验证 T 出生点→A 大/B 洞、中路→猫道→A 小、CT→A/B 等关键走位。

## 2. 角色

`src/render/character.ts` 用盒体搭出**独立的头、躯干、双臂（上臂+小臂+手）、双腿（大腿+小腿+靴子）**，共 27 个网格、带关节层级：

- 走路时腿部摆动、小腿弯曲、髋部反向扭转与上下起伏；空中/蹲下有单独姿态；阵亡时身体倒地。
- 上半身随视角俯仰旋转，武器挂在右手上，因此**武器始终跟随角色朝向**。
- **CT**：藏蓝制服 + 头盔 + 护目镜 + 浅蓝肩带；**T**：沙色制服 + 红色头套 + 橙色头带。一眼可区分。

## 3. 武器

| 武器 | 伤害 | 射速 | 弹匣 | 特点 |
| --- | ---: | ---: | ---: | --- |
| AK-47 | 36 | 600 RPM | 30 | 后坐力最强（垂直 1.7°/发 + 横向漂移），扩散增长快 |
| M4A4 | 30 | 666 RPM | 30 | 后坐力低、射速高、扩散恢复快 |
| AWP | 115 | 41 RPM | 10 | 右键两级开镜（FOV 30→12）+ 2D 瞄准镜遮罩，移速最慢 |
| Glock-18 | 28 | 400 RPM | 20 | T 默认手枪 |
| USP-S | 35 | 352 RPM | 12 | CT 默认手枪，消音（枪声明显更闷更轻） |
| Desert Eagle | 63 | 267 RPM | 7 | 介于手枪与步枪之间，弹匣小、后坐力大 |
| 匕首 | 55 | — | — | 近战 |

- **命中分区**：头 ×2.0、腹 ×1.25、胸 ×1.0、手臂/腿 ×0.75。按题目要求**爆头 = 身体伤害的两倍**（正式 CS 为 4 倍，此处遵循题目）。
- **护甲**：`穿透率` 决定透过护甲的伤害，其余的一半消耗护甲值；头部只有戴头盔才受护甲保护。
- **扩散/后坐力**：站立、移动、跳跃、下蹲、连发累积各自独立建模；开火会抬升视角（`viewPunch`），子弹沿被抬升后的方向飞出，停火后回落。AI 会按自身水平做部分压枪补偿。

## 4. 手枪局

主菜单可勾选「只打手枪局」；默认第 1 回合即为手枪局：无主武器、只有阵营默认手枪、CT 有护甲无头盔。之后回合自动全装（每队 1 把 AWP + 步枪 + 少量沙鹰，部分 CT 携带拆弹器）。

## 5. C4 与回合胜负

- 回合开始随机交给一名 T；持包者阵亡 → C4 掉落在原地 → 其他 T 走过即可拾取（背包模型会显示在持包者背上）。
- **下包**：持包 T 站在 A/B 点范围内按住 `E`，3.2 秒完成；移动或松手会中断。安放后 40 秒倒计时，蜂鸣频率随时间加快。
- **拆包**：CT 站在 C4 处按住 `E`，10 秒（带拆弹器 5 秒）。
- **结算**：T 清空 CT / C4 爆炸 → T 胜；CT 拆包 / 在下包前清空 T / 时间耗尽 → CT 胜。**已下包时清空 T 不算 CT 获胜**（与 CS 规则一致）。
- 阵亡后自动进入队友第一人称观察，`空格` 切换目标，`F` 直接接管该 bot 继续战斗。

## 6. AI

每个 bot 拥有一个 `BotBrain` 状态机：`advance / engage / search / hold / plant / defuse / pickupBomb`。

- **感知**：约 10 Hz 扫描，105° 视野锥 + 视线射线（被墙挡住看不见），近距离移动的敌人可被「听」到。
- **情报共享**：看到敌人会写入队伍情报表；队友阵亡时该队伍会得知击杀者位置——这也是 CT 换点支援的依据。玩家看到的敌人同样写入情报（因此会出现在小地图上，队友 AI 也会做出反应）。
- **交战**：转头速率、瞄准误差、反应时间由 `skill` 决定；静止预瞄的 bot 反应更快（防守方优势）；自动武器点射、狙击枪单发；**不会穿队友开枪**（开火前做一次射线检查）。
- **导航**：A* + 路径拉绳平滑 + 卡墙检测（贴墙磨蹭超过 0.7 秒会重新规划并侧向脱困）。
- **战术**：T 方随机选点，按 Long / 中门→猫道 / B 洞等真实路线分散推进，最后一名做 lurker 骚扰另一个点；持包者进点安放，包已下则改为守点。CT 方 2-2-1 分守（两点各两人 + 一名机动），**只有在收到明确情报且己方点位安静时才换点**（避免在开阔地被路过打死），下包后全员奔向 C4 拆除。
- **守点角度**：守点方向不是简单地朝向敌方出生点（那样经常在对着墙），而是从敌方出生点向自己的位置做一次寻路，回溯约 8 米，面向敌人真正会走出来的那个位置。

## 7. HUD

顶部回合计时/比分/存活人数、左上小地图、右上击杀播报、左下血量护甲、右下动态弹药与武器栏、中央动态准星（随真实扩散张开）与命中标记、下包/拆包进度条、受伤红色暗角、C4 倒计时警示、`Tab` 记分板、AWP 瞄准镜遮罩。

**小地图**常驻显示 Dust2 俯视轮廓（与碰撞体同源数据）、A/B 点标记、自己（含视野扇形）、队友、**被己方看见过的敌人**（4 秒记忆）以及 C4 位置与状态。

## 8. 音效

`src/audio/audio.ts` 全部用振荡器与噪声缓冲合成，每个声音由「瞬态爆音 + 低频腔体 + 机械环」分层构成，各武器有独立的滤波与衰减特征：AK 低沉厚重、M4 更紧更亮、AWP 巨响长尾、手枪清脆、USP 消音沉闷。另有换弹、上膛、切枪、脚步（静步更轻）、跳跃落地、开镜、命中反馈、受伤、击杀提示、C4 蜂鸣/安放/拆除/爆炸、回合开始与胜负提示。

声音按位置混音：距离衰减 + 立体声声像 + 空气吸收低通；**被墙体遮挡时会额外低通并衰减**，所以能听出「墙那边在交火」。

## 测试

因为模拟层不依赖 three/React，`npm test` 可以直接用 Node 原生 TypeScript 支持无头跑完整比赛（约 100 项断言）：

| 套件 | 覆盖 |
| --- | --- |
| `tools/statictest.ts` | 导入解析、括号配对、JSX 标签闭合、**分层约束**（模拟层不得引入 three/React） |
| `tools/maptest.ts` | 扇区高度一致性、地图封闭性（射线泄漏检测）、24 个战术点全连通、出生点与炸弹点合法、中门可通行 |
| `tools/simtest.ts` | 30+ 回合无头对局 + 一整场打到分出胜负：无 NaN、**任何人任何时刻都不会卡进墙里**、双方都能获胜、四种胜负条件均可达成、下包/拆包/爆炸/掉落拾取全流程、手枪局只出手枪、伤害模型（爆头 2 倍、护甲、头盔、AWP 一枪致命）、武器机制（打空自动换弹、后坐力抬升与回落、扩散增长、AWP 两级开镜）、玩家操控与阵亡接管、实时性能（约 60µs/tick，即实时的 250 倍速） |

## 已知取舍

- **爆头倍率**按题目要求设为身体的 2 倍（正式 CS 是 4 倍），可在 `src/game/hitbox.ts` 一处改回。
- **没有经济系统**：回合装备按「第 1 回合手枪局，之后全装」的固定策略发放，而不是买枪菜单。
- **平衡偏 T**：纯 bot 对局中 T 方胜率约 7:3（48 回合样本：T 36 / CT 12，四种胜负条件均有出现）。原因是结构性的：AK 单发伤害显著高于 M4（题目明确要求的手感差异），而真实 CS 里 CT 的劣势由烟雾弹、闪光弹和 pre-fire 补偿——本原型没有投掷物系统。已通过「静止预瞄的防守方反应更快」「守点朝向按真实进攻路线计算」「CT 只在明确情报下换点」「T 方留 lurker 不五人抱团」把 CT 胜率从 ~12% 提到 ~25%，进一步平衡需要引入投掷物或交叉火力站位评分。玩家加入任一阵营都会明显改变这个比例；主菜单的 AI 难度滑条对双方同时生效。
- **单层导航**：导航网格是单层栅格，因此楼层平面里没有真正意义上的立体交叉（Dust2 原图中猫道与中路的重叠部分做了简化）。
- 渲染层的无头测试只能验证结构与数值（Node 没有 WebGL 上下文），画面效果需要在浏览器里观察。
