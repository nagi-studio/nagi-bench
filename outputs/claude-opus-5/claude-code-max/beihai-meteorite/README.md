# 陨　石

一部在浏览器里运行的程序化体素电影，改编自刘慈欣《三体 · 黑暗森林》中
章北海购买陨石、加工陨石子弹、并在同步轨道上完成刺杀的段落。

全长 **358 秒**（硬上限 360 秒）。画面、模型、贴图、特效全部由代码生成，
不使用任何外部素材；音效来自平台提供的离线 CC0 采样库，另有一层程序化
Web Audio 负责房间、身体和主观声。

```bash
bun run build      # 产出标准 Vite dist/
bun run dev        # 本地开发服务器
bun run check      # 时间轴 / 语音清单 / 声音清单 的无浏览器自检
bun run check:audio  # 用假 AudioContext 跑一遍全部声音提示
bun run preview:frames  # 用自带的软件光栅器把若干时刻渲成 PNG（检片用）
```

`dist/index.html` 可以直接在浏览器里打开（`base: "./"`），也可以由任何静态
服务器托管。

## 改编取舍

原文是一段"买石头 — 加工 — 杀人"的线性叙事。这一版做了四处结构上的决定：

1. **先给结果，再给过程。** 影片从一块翻滚的铁陨石和真空中一个等待的白点
   开始，然后才回到三个月前的北京。观众带着"他在等什么"看完整个四合院段落。
2. **四合院是全片的情感锚点，不是过场。** 它占了 84 秒，是全片最长的一场戏，
   因为章北海的可怕正来自于这场戏的温暖 —— 一个人守着自己的小世界，
   而买石头的人正在为一件他绝不会说出口的事做准备。
   「明白了，要雕刻是吧。」和「就算表示我，对要送的人的尊重吧。」
   是整部影片的支点，片尾字幕重复了后一句。
3. **动机只交代一次，而且说得很平。** 「而决定飞船走哪条路的，是航天界最有
   分量的几个人。」全片再没有第二次解释，直到弹道飞行的那十秒里他自己承认
   「他们也是无辜的」。
4. **章北海在地球上几乎不说话，在真空里才开始想事情。** 他的内心独白只出现在
   没有人能听见的地方 —— 这是刻意的角色设计，也是声音设计。

被删掉的：火星陨石的报价、韦氏条纹与牛曼条纹的矿物学、增援未来计划的组织
细节、太空电梯与聚变的宏观论述（压缩成 15 秒的旁白蒙太奇）。

## 视听体系

| | 地球 | 真空 |
| --- | --- | --- |
| 光 | 琥珀色的斜阳、一盏台灯、一排荧光灯、一只钨丝灯泡 | 一颗正在沉下去的太阳，加一层地球反照 |
| 声 | 有房间：脚步、玻璃、木头、机床，地下室枪声挂程序化卷积混响 | 没有房间：舱外一切无声，只剩呼吸、系统低频、无线电和枪机传导的闷震 |
| 机位 | 手持微颤，反打，越肩 | 绝对平稳，只有失重的漂移 |

太阳的高度角是太空段落唯一的时间线索：从 -6 度一路走到 -18 度。
`setSun()` 里的几何是按"从章北海那里看，地球角半径约 30 度"算的，
所以太阳恰好在合影进行到一半时沉进地球的边缘。

真空里的枪声按物理处理：三十次击发全部只有 `vacuum-thump`（程序化的低频闷震，
模拟经由手套和骨骼传导），舱外的碰撞、泄压、推进器一律不出声；
观众能听见的只有公共频道被叫爆的削波。`bun run check` 会强制校验这一点。

## 目录

```
src/
  timeline.ts      全片 29 个分镜的绝对时间表，其他所有文件都引用它
  voice.ts         唯一的一份语音清单（87 条，七个固定字段），字幕由它驱动
  sound.ts         采样注册 + 程序化声音工厂 + 184 条声音提示
  shots.ts         分镜、机位、表演、转场、片名
  film.ts          装配：播放器、舞台、音频总线、控制条
  cast.ts          全部角色（voxel-kit createFigure）与手上的道具
  art/skins.ts     所有 64×64 皮肤表：五官、眼镜、肩章、面罩裂纹全是像素
  art/props.ts     手枪、瞄准镜、弹夹、茶杯、钳子……用字符立面图挤出来
  sets/            四合院、车间与地下室、轨道
  lib/             体素工具、机位工具、瞄准镜与面罩、画面之上的一层
tools/             无浏览器自检与软件光栅器（不参与构建）
```

## 自检说明

本机没有可用的浏览器（`chromium-browser` 需要 snap，环境离线），
所以浏览器内的实际点击播放无法在这里完成。作为替代，仓库内提供了三层验证：

- `tools/headless-check.ts`：构建完整场景，以 1/30 秒步长把 358 秒全部 `seek`
  一遍（10741 帧），校验分镜连续性、机位有限性、语音字段与语速、声音区间、
  真空静默约束，并在 19 个时刻做两次不同路径的求值以确认确定性。
- `tools/audio-check.ts`：用假 `AudioContext` 触发全部 184 条声音提示，
  确认采样解码与程序化工厂都不抛异常。
- `tools/render.ts` + `tools/preview.ts`：一个自带的软件光栅器（z-buffer、
  逐像素 UV、背面剔除、按 three.js 口径的物理光照、精灵与点云），
  把任意时刻渲成 2.39:1 的 PNG，用来实际"看"构图、遮挡、明暗和贴图。
  `tools/figures.ts` 按体素规格的要求，把每个角色正面和侧面各出一张。
