# 水运仪象台 · 把流水变成时间

一部约 32 秒、可离线直开的中文 3D 科普短片。采用剖面木构、青铜齿轮与青绿色水流，依次解释：

**平水壶 → 受水斗与水轮 → 天衡擒纵 → 齿轮传动 → 木人击鼓 / 浑仪。**

## 运行

```sh
bun run dev       # 开发服务器
bun run build     # 标准 Vite 生产构建，输出 dist/
bun run preview   # 预览生产构建
```

`dist/index.html` 也可以直接用现代浏览器打开，无需服务器或网络。

- 自动播放；浏览器阻止自动声音时，点右上角「开启声音」。
- 空格：暂停 / 继续；`M`：声音开关；`R`：重播。
- `?t=19`：从片头开始进行物理积分，然后定帧在指定秒数，便于检查镜头（不播放声音）。

## 实现

- **Three.js**：所有建筑、器械、文字盘面和贴图均在运行时生成，无外部模型、贴图或字体文件。
- **Rapier 3D**：水轮、锁爪、报时杠杆、木槌、立轴和浑仪均为动态刚体，渲染只读取物理变换。
- 离散水滴具有重力、速度与碰撞；连续水头以速度相关力矩补充驱动。
- 齿轮采用带双反作用力的速度约束冲量，按齿数传递动力；直角锥齿轮同样由约束驱动。
- 擒纵与报时拨钉使用等效凸轮力矩；木槌与鼓面使用真实碰撞事件触发报时。
- **Web Audio API**：五声音阶拨弦、低音铺底、流水、滴答与鼓声全部运行时合成，无音频文件；主输出带动态压缩。
- 固定 60 Hz 物理步长，低帧率下追帧；软件 WebGL 自动降低内部分辨率。

这是帮助理解传动关系的结构原理演示，并非等比例考古复原；为在短片中看清动作，转速已加快。

## 自检

```sh
bun run check:offline  # offline:true + file://，检查网络、报错、暂停/继续、声音与重播
bun run check:shots    # 七个精确秒数的物理定帧截图，输出 held-preview/
```

沙箱自检浏览器路径写在 `checks/` 脚本中。正式运行只依赖 `three` 与 `@dimforge/rapier3d-compat`。
