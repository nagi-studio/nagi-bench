# 以水度量星辰 · 苏颂水运仪象台

一段约 30 秒的离线 3D 科普短片。使用 Three.js、Cannon-es 与原生 Web Audio API；模型、材质、水流、配乐和音效均在运行时生成，没有外部模型、贴图或音频文件。

## 运行

```sh
bun run dev
bun run build
```

构建产物在 `dist/`。`dist/index.html` 使用本地经典脚本与相对路径，可直接通过 `file://` 离线打开，无需服务器或网络。浏览器若限制自动播放声音，点击右上角“开启声音”或页面任意位置即可。

附加的定位方式：`dist/index.html?t=12` 从第 12 秒镜头开始；`?t=12&freeze=1` 冻结在该镜头，便于教学与检查。

## 物理实现

- 水滴是受重力、发生碰撞的刚体；进入受水斗后增加该斗载荷，载荷对轮轴产生重力矩。
- 水轮、枢衡、齿轮、立轴、浑象和钟锤均为动态刚体，画面只同步物理刚体的位置与姿态。
- 枢衡使用按水轮驱动力矩计算的止逆、释放和回位力矩，逐斗索引；没有旋转关键帧。
- 齿轮由自定义 Cannon 速度/位置约束交换成对求解冲量，保持 12:24 的传动比。
- 报时凸轮依据实际轴相位施加接触力矩；钟锤由弹簧回摆，与钟的真实碰撞触发钟声。
- 所有机械积分使用固定 90 Hz 子步。镜头、字幕与声波光环不属于机械机构。

报时间隔为短片做了压缩，木塔采用便于观察因果链的剖面结构示意。

## 自检

`checks/sim.mjs` 连续运行机构并输出轮角、各轴速度、擒纵与撞钟数据；`checks/browser.mjs` 用 Playwright 通过 `file://` 逐镜截图并收集控制台错误。根目录 `preview/` 为默认播放的自检截图，均不在 `dist/` 中。
