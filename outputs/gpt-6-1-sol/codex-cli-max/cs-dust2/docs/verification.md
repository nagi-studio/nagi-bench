# 验证记录

验证日期：2026-10-23。浏览器：Chromium 156，WebGL 2；项目运行时依赖仅 React 18、React DOM 和 three.js。

## 可复跑检查

```sh
npm run check
npm test
npm run build
```

全部通过。`npm test` 不依赖测试框架，直接验证实际地图与武器模块：

- 九个关键位置之间的 36 组路径全部连通，1,101 个有效导航节点构成单一连通区域。
- 出生位置可用，长距离移动不会穿墙，箱体和中门门板有实体碰撞。
- 中门门缝可走、可见；门板阻挡视线。
- A 平台与猫道高差存在。
- 两处交火侧移后的 CT 墙角位置均能继续沿路径移动，覆盖贴墙恢复的回归检查。
- 七种武器的爆头倍率、护甲、AWP 躯干致命伤害、射速、后坐力、弹匣及五类 Hitbox 规则正确。

## 浏览器交互与对局

通过 27 项浏览器检查，包括真实键鼠事件驱动的指针锁定、WASD、跳跃、自动射击、半自动扳机、换弹与备弹扣减、三类武器切换、军械库、AWP 冷却、3D FOV 拉近和 2D 瞄准镜遮罩。

实际角色网格射线命中验证了头部与胸部伤害；所有十名角色均有五类命中部位。手枪局配置作用于全员，第二回合恢复完整装备。

C4 验证覆盖持续安放、中断重置、持续拆除、爆炸、持包者死亡掉落、队友拾取、下包后 T 全灭仍需拆弹、未下包 T 全灭的 CT 胜利，以及死亡后观战与接管。观战对象再次死亡会自动选择存活队友，回合结束后仍会完成倒地动画，离地会中断拆包。

最终连续模拟 180 秒，完成 4 个回合，CT、T 各胜 2 局，观察到真实交战、下包、持包转移和回合重置；存活角色位置采样未发现墙体或箱体穿透，也未检测到需要前进时持续 5 秒停滞的 AI。爆炸与拆除结算另由交互测试和目标流程测试验证。浏览器无运行异常、无外部资产请求。

另行隔离交火干扰测试 AI 目标流程：T AI 从出生点经 A 大或 B 洞推进，在 A、B 两点均成功安放；CT AI 均能寻路到炸弹并完成拆除。连续交火模拟则验证了目标流程与战斗的组合行为。

修正了 AI 侧移与寻路移动碰撞半径不一致导致的贴墙停滞，两种移动现在共用 `ACTOR_RADIUS`。重放连续对局中发现的两个停滞位置后，CT AI 分别在 11.75 秒与 15.67 秒内抵达 A、B 点并完成拆包；对应路径已加入 `npm test` 回归检查。
