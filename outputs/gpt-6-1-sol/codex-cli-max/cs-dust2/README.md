# DUST II — Protocol

可在浏览器运行的单机 5v5 战术 FPS 原型。React 18 + TypeScript + three.js；全部几何模型、场景与 Web Audio 音效由代码生成，无外部模型、图片、贴图、音频、字体或 CDN。

```sh
npm install
npm run dev
```

需要 Node.js 22.12+ 或 20.19+。打开终端显示的地址（默认 http://localhost:5173）。使用支持 WebGL 2 的桌面浏览器，点击「开始行动」锁定鼠标。`npm run build` 生成 `dist/`，`npm run preview` 预览生产构建。

`npm run check` 检查 TypeScript；`npm test` 验证全部核心区域之间的 36 组路线、碰撞、门缝、视线、地形、贴墙回退和武器伤害规则。浏览器交互与 AI 连续对局详见[验证记录](docs/verification.md)。低性能设备可在地址后附加 `?quality=low`，降低渲染分辨率并关闭实时阴影；软件渲染会自动使用此设置。

## 玩法

- 1 玩家 + 4 队友，对抗 5 名 AI，可选择 CT / T。AI 自主走位、有视野遮挡、反应延迟、连发、换弹和目标行动。
- T 出生点经 A 大门至 A 大/A 点；中路经中门连 CT 出生点；中路经猫道至 A 小/A 点；T 斜坡经 B 洞至 B 点，B 下层通道连接中路；CT 出生点经 B 门连接 B 点、经斜坡连接 A 点。猫道和 A 平台有可步行高差，中门门体有碰撞且保留通路。
- T 清空 CT 或引爆 C4 获胜；CT 在未下包时清空 T、守到回合超时，或成功拆包获胜。下包后即使 T 全灭，CT 仍须拆弹。C4 倒计时 40 秒。
- 每回合结束后 5 秒自动开下一回合。T 的主要进攻目标在 A / B 之间轮换。
- 可选手枪局：仅第一回合全员配备 Glock / USP、25 护甲，无主武器。第二回合恢复完整装备与 100 护甲。
- AK / M4 / AWP / Glock / USP / Desert Eagle / 匕首有独立数据与模型。头部伤害为胸部两倍，腹部 ×1.12、手臂 ×0.72、腿部 ×0.62；非腿部命中受武器穿甲率与剩余护甲影响。AWP 胸部命中可一枪击杀满甲目标。
- 小地图显示地图轮廓、掩体、自己、队友、最近 2 秒被友军看见的敌方最后位置，以及 C4。
- 按 Esc 会暂停整个本地模拟；切换窗口或失去指针锁定也会暂停。

## 架构

```
src/game/Engine.ts   固定 60 Hz 模拟、回合、输入、武器、AI、C4、事件、快照
src/game/map.ts      共享地图、地形高度、碰撞、射线遮挡、手写 A* 与路径简化
src/game/models.ts   分部位类人角色、持枪姿态、第一人称武器、C4
src/game/weapons.ts  可扩展武器表、Hitbox 倍率与护甲伤害计算
src/game/world.ts    程序化几何场景、日照、阴影、雾、第一人称模型渲染
src/game/audio.ts    Web Audio 合成器、距离衰减与立体声方向
src/ui/             React 菜单/HUD、Canvas 小地图、装备与比分界面
```

模拟状态归 `GameEngine` 管理，以不可变快照每秒 12 次通过 `useSyncExternalStore` 同步 React；渲染与 Canvas 小地图独立刷新。RAF 采用固定步长累加器，墙体使用同一套 AABB 做移动碰撞和视线遮挡；子步进与双轴滑动避免穿墙。AI 在保留角色半径的网格上手写 A\*，对路径进行碰撞感知的直线简化。命中检测对角色实际分部位网格做射线检测，取墙前最近命中。生命周期会释放输入监听、RAF、音频上下文和 GPU 资源。

地图为自行搭建的 Dust2 核心区域拓扑与视觉风格原型，尺度与细节经过简化；不是原作地图资源的逐像素复现。项目是离线 AI 对战，不含联网、经济系统、投掷物或原版游戏资产。
