# DUST II — Field Operations

一个可直接游玩的浏览器单机 5v5 FPS 原型。React 18 + TypeScript + three.js；运行时依赖仅 `react`、`react-dom`、`three`。没有模型、贴图、字体或音频等外部资产，没有网络游戏服务器。

## 运行

推荐 Node.js 22，以及支持 WebGL 2、Pointer Lock、Web Audio 的桌面浏览器。

```bash
npm install
npm run dev
```

打开终端打印的本地地址，选择阵营、开局模式与装备，点击「进入战场」。浏览器会锁定鼠标并启用声音。`Esc` 暂停模拟、释放鼠标；「继续行动」恢复。

```bash
npm test          # 直接验证 TypeScript 游戏系统
npm run check    # 严格类型检查
npm run build    # 生成 dist/
npm run preview  # 本地预览生产版本
```

## 对局规则

- 共 10 名角色，选择的阵营为 1 名玩家与 4 名 AI，敌方 5 名 AI。阵亡后仍可接管存活队友；观战期间队友继续由 AI 控制。
- 每回合 3 秒准备、115 秒战斗。回合结束后 7 秒自动开始下一局，累计双方比分。
- 「手枪开局」首回合所有 T 仅带 Glock、所有 CT 仅带 USP-S，均无主武器、无护甲，保留近战刀；第二回合起恢复全装。全装开局可选择 AK-47 / M4A4 / AWP，以及默认手枪或沙鹰。
- 回合开始由一名 T 携带 C4；玩家选 T 时初始持包。持包者阵亡会掉包，其他 T 靠近自动拾取。包会落在地面或箱顶支撑面。
- T 在 A / B 范围内长按 E **3.2 秒**安放；C4 在 **40 秒**后爆炸。CT 全装配有拆弹器，需要 **5 秒**；手枪局需要 **10 秒**。松开 E、移动或离开有效范围会清空进度。
- T 消灭全部 CT 或引爆 C4 获胜；CT 拆除 C4、在未安放时消灭全部 T，或守到未安放的回合计时结束获胜。C4 已安放时，T 全灭仍须拆除。
- 头部原始伤害为胸部 **2 倍**；腹部 1.15 倍、手臂 0.72 倍、腿部 0.65 倍。护甲根据武器穿甲系数吸收并消耗，腿部不消耗护甲。AWP 可单发击杀；友军会挡住射线，不承受友伤。

## 地图

按约 1 单位 = 1 米的尺度重建 Dust2 核心区域及连通关系，属于几何体风格的路线复刻，不是原版 BSP 的逐面移植。

```text
                           T 出生点
                    ┌────────┼─────────┐
                  上层 B 洞  上中路    A 大外侧
                    │        ├─ 猫道     │
                  B 洞 ─ 下层洞 │       A 大门
                    │        │ A 小道    │
                  B 点      中门 │       A 大 / 大坑
                    └─ B 门 ─┼───┼───── A 点（抬高）
                            CT 出生点 ─ CT 坡道 ┘
```

所有封闭墙、可见建筑主体、门板和掩体都有碰撞；中门保留真实可穿行的中心间隙。A 平台采用连续高度场坡道；B 上下层通路有实体屋顶、出口和程序化灯光。雷达复用区域轮廓与实体障碍，显示自己、队友、最近被本方看到的敌人，以及可知的 C4 状态。

## 实现结构

| 文件 | 职责 |
| --- | --- |
| `src/game/engine.ts` | 权威对局状态、60 Hz 固定步长、输入、C4 状态、回合结算、插值渲染、资源释放 |
| `src/game/world.ts` | 区域并集、地形高度场、几何建筑、门板、碰撞数据与掩体 |
| `src/game/navigation.ts` | 自行实现二叉堆 A*、障碍膨胀、禁止对角切墙、可见直线简化路径 |
| `src/game/physics.ts` | 圆形人物水平碰撞、轴向滑动、运动细分、重力、跳跃、坡道与箱顶支撑 |
| `src/game/bots.ts` | 推进、巡逻、索敌、交战、捡包、安放、回防拆除；视锥、墙体射线遮挡与局部分离 |
| `src/game/weapons.ts` | 可扩展武器数据、分区倍率、穿甲与护甲消耗 |
| `src/game/hitboxes.ts` | 将射线变换到角色局部坐标，分别测试头、胸、腹、双臂、双腿 |
| `src/game/models.ts` | 独立头身手足、阵营装束、持枪姿态、步态、所有武器和 C4 的程序化模型 |
| `src/game/audio.ts` | Web Audio 振荡器、噪声、滤波、包络、距离衰减与立体声声像 |
| `src/ui/` | React 开局、暂停、HUD、雷达、记分板与观战提示 |

渲染与物理不经 React 更新。引擎通过 `useSyncExternalStore` 每约 85 ms 发布不可变 HUD 快照；3D 相机、后坐力、角色动画在渲染循环中更新。卸载时清除 RAF、DOM 事件、ResizeObserver、音频上下文、几何体、材质和 WebGL 资源。

建筑采用带实例颜色的 `InstancedMesh`，角色按骨骼节点合并顶点颜色几何，减少提交次数。GPU 渲染使用方向光阴影。软件渲染使用顶点烘焙光照、关闭阴影，并按实测帧率自适应降低 3D 分辨率；React HUD 始终保持原生清晰度。没有第三方物理、寻路或游戏引擎。

## 验证

`npm test` 包含 7 项系统测试：完整区域与双方出生点到两点的连通性、四条推进路线、实墙阻挡、跳跃与箱顶/坡道/离台支撑、中门的通行与视线、五类 Hitbox，以及伤害/后坐力/射速/护甲关系。

开发时还在 Chromium 中检查了真实鼠标锁定、WASD、半自动与连射、换弹、AWP FOV 和镜框、命中击杀、掉包拾包、接管、长按安放、拆除中断和成功、爆炸胜利、各类回合判定与手枪局切换。固定随机序列的完整 AI 对局中，10 人均移动，产生 8 次击杀，并完成自主安放、回防、拆除及胜负结算；存活角色未进入碰撞实体。

开发模式在 `window.__DUST__` 暴露引擎用于复现和检查；生产构建不暴露此入口。

本次 Chromium 环境使用纯软件 WebGL，功能流程均已验证，但持续运行帧率仍偏低；流畅度需要在开启硬件加速的桌面浏览器上进一步验收。
