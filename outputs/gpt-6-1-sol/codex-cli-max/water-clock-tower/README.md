# 以水为钟

约 32 秒的中文 3D 科普短片，解释北宋苏颂水运仪象台的「均匀供水 → 水斗增重 → 衡杆释锁 → 水轮定步 → 齿轮传动 → 天象与报时」。

**直接观看：双击 `dist/index.html`。** 所有资源都在本地；构建入口使用经典 IIFE 脚本，因此 `file://` 下也可运行，无须服务器。画面自动播放；点击「开启声音」启用程序合成配乐、水声、机械声与钟声。

```sh
bun run dev
bun run build
```

播放键 / 空格暂停；进度条或章节按钮跳转；左右箭头前后跳 5 秒；M 切换声音；右上角 i 查看史实与简化说明。跳转会从初始状态重新求解物理，可能有短暂计算时间。

## 实现

- Three.js 0.180.0：程序生成的木构、受水轮、开放水斗、齿轮、浑仪、浑象及报时木偶；没有模型、贴图、字体或音频等外部素材。
- Cannon ES 0.20.0：固定 1/120 秒步长，动态刚体通过真实铰链轴承约束；自定义角度约束在同一冲量求解器内传递齿轮的力矩。没有机械关键帧、预设角速度或随影片时间设置机械位置的代码。
- 受水粒子由重力积分下落，被水斗捕获后转移质量与冲量；积水参与重力力矩和转动惯量。衡杆由水重、配重、弹性与阻尼决定姿态。衡杆达到几何释锁阈值后，下一道止齿接触限制水轮的推进角度。
- 天柱、浑象、浑仪、报时轮和拨轮均由约束传动。凸轮接触力抬起槌臂；重力使槌臂落下，敲击接触把冲量交给铜钟。音效取自真实释锁和敲击事件。
- Web Audio API：运行时生成噪声、拨弦和钟的模态振荡器；主增益平滑变更并经过动态压缩器，避免突发音量。浏览器首次出声需要点击。
- 机械姿态完全读取物理刚体。只有镜头、字幕与解释性箭头按分镜编排；暂停会冻结求解，跳转通过重算完成。

## 历史与演示范围

以苏颂《新仪象法要》记录的工作原理为依据，展示等效机械关系，并非精确复原原机。原枢轮的 36 个受水斗简化为 12 个，复合止轮结构以衡杆及单级止齿表示，原机齿轮、天梯等传动路径压缩为可见的齿轮与天柱。天文转速、拨牙数量、时间及尺寸均为教学而调整。片中无法读取真实天象或历史时刻。
