# 导演与声音设计

片名《尘外》。画面从“宇宙中的石头”走向“人制造的陨石雨”，再回到茶杯。章北海不被处理为胜利者：无辜者的脸先于枪口出现，五名伤者和未定的航线留在结尾。所有语言都集中在 voice-cues.json；表中其他文字均为场记或无声画面信息。

| 时间（秒） | 镜头与表演 | 声音意图 |
| --- | --- | --- |
| 0–16 | 地球、轮形站、极小的孤身航天员；片名缓慢出现 | 内部呼吸、低音，两句以内心声等待日落 |
| 16–26 | 胡同中的背影走向旧宅 | 稀薄风声、低而干的石板脚步 |
| 26–39 | 暖灯、陈列柜、两人隔桌；收藏者打开手势 | 温和的日常闲谈、房间底噪，和后段拉开距离 |
| 39–50 | 茶杯与三块石头的低机位近景 | 杯沿清脆一响；章北海关于地球的玩笑 |
| 50–61 | 桌上三块石头；收藏者微俯身介绍 | 石头逐次落桌，不展开技术教学 |

| 263–271 | 匹配切回仍冒热气的茶杯，人物消失 | 收藏者的温暖记忆；稀疏和声，无安慰性结论 |
| 271–278 | 死亡数字、事故归因与仍未确定的未来；片名终帧 | 和声缓慢衰减至静默，画面在 278 秒停住 |

色彩的顺序：青黑与微金 → 旧木与蜂蜜色 → 机床冷青 → 地下室灰绿 → 蓝黑轨道与日落金 → 暖色茶杯的空场。机位在准备阶段越来越近，抵达太空后骤然放远；日落中的三十次微小火光与其造成的巨大后果构成尺度反差。
