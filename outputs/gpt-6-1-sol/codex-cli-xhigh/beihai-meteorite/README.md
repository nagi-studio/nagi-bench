# 尘外 · Beyond the Dust

一部 **4 分 38 秒（278 秒，含片头片尾）** 的 Three.js 程序化体素电影。

观看构建产物：`dist/index.html`。在静态 HTTP 服务中打开即可；入口保留对本地 `assets/` 的相对引用。没有外部模型、图片、字体、音频或 CDN 请求。

```sh
bun run dev
bun run build
bun run preview
```

依赖使用案例预装的离线工具链，**不需要执行 install**。只声明 Three.js、Vite 和指定的 Cinematic Player / Voxel Kit。

点击「开始观影」同时解锁 Web Audio。底栏提供暂停、时间轴、音量及全屏；空格切换播放，方向键跳转五秒，F 全屏。任意跳转使用同一条绝对时间轴。浏览器需支持 WebGL 2 与 Web Audio API。

## 改编

保留收藏者、三块陨石、加工、地下室验证、离开定位器、轨道日落与合影袭击。删去交易中的地质讲解、详细的弹药制作步骤及大段世界背景。以太空等待开场，把袭击动机延后到航天船坞与评审记录，再以「他们不是敌人」直接面对人物的道德选择。十秒飞行等待按真实十秒呈现。最后回到茶杯：收藏者珍爱的日常和章北海声称保护的未来，已经彼此疏离。

## 配音交接

唯一完整人声清单是 [`src/voice-cues.json`](src/voice-cues.json)，由 `src/main.js` 导出为 `voiceCues`，字幕直接读取它。28 条 cue 每条严格具有 `id / kind / speaker / text / delivery / start / end` 七字段；时间单位为秒。所有人声仅以固定底部居中的 `【说话者】文本` 出现，无 TTS 或其他人声合成。后期可按 id 逐条录音。

## 声画实现

- 26 个独立镜头；总时长由 `src/shots.js` 中的 `DURATION` 固定。
- 全部角色使用 Voxel Kit 的 `createFigure`、统一骨架和独立服装贴图。五官、头盔、破裂与服装标记均画在贴图中。道具通过 Kit 的 `voxelModel` 及挂点装配。
- 岩石、地球和空间站轮缘使用 Kit 的合并体素几何；木地板、窗棂、机床与桁架保持方块语言。模型、贴图与粒子全部运行时生成。
- 全部音效与配乐用 Web Audio 节点和确定性的计算噪声合成。地下室枪声有多次早期反射与渐暗的混响尾声；轨道枪声只有航天服内传导的低频闷震。外部失压完全静默，撤离警报来自通讯频道。推进声属于航天服内部主观听感。
- 每次暂停或跳转，播放器音频总线停止旧节点，并按 cue 重新建立持续环境声；镜头与表演由绝对时间计算。

`DIRECTOR.md` 包含剪辑、表演与声音的镜头表。`tools/browser.mjs` 是无第三方依赖的 CDP 检查脚本，不参与构建或影片运行。开发检查可通过 `window.film.player` 使用正常播放、暂停、seek API。

## 验证

已实际执行 `bun run build`。浏览器中实际点击播放并确认推进，检查暂停保持、时间轴拖动、合影/失压之间的往返跳转。另以低分辨率 16 倍速、10 fps 的软件渲染巡检完整到达 278 秒终帧，26 个镜头全部经过、104 条声音 cue 执行，未发现页面控制台异常。记录见 [`tools/verification.json`](tools/verification.json)。
