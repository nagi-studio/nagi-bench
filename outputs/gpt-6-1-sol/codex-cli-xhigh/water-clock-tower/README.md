# 水落 · 星移

30 秒浏览器 3D 科普短片，讲解北宋苏颂水运仪象台的水力、擒纵、传动和报时。所有模型均用几何体构造，配乐与音效全部通过 Web Audio API 实时合成，无外部模型、纹理、字体或音频资源。

## 打开与开发

- 直接双击 **`dist/index.html`**，可离线播放。点击右下角「开启声音」启用配乐与音效；浏览器需要这次用户手势才能开启音频。
- `bun run dev` 启动 Vite 开发服务器。
- `bun run build` 重新生成 `dist/`。
- `bun run verify:physics` 检查完整 30 秒的机械约束、击钟接触、轴承稳定性，以及断水后不自行启动。

空格暂停／继续，R 重播，M 开关声音。进度条和章节名均可跳转。跳转时重新运行物理解算至目标时刻，不使用预制的机械动画。

## 影片结构

| 时间 | 画面与因果 |
| --- | --- |
| 0–4 秒 | 仪象台全貌：观天、演象、报时 |
| 4–9 秒 | 平水壶稳水位，受水壶积水增重 |
| 9–15 秒 | 水重压天衡，关舌释放，枢轮前进一步，再锁住 |
| 15–20 秒 | 枢轮经齿轮与立轴，把动力送至浑象、浑仪 |
| 20–26 秒 | 凸轮顶动滚轮随动件，经连杆带动木偶槌臂，击钟与时牌报时 |
| 26–30 秒 | 全景回收：水重 → 擒纵 → 传动 → 报时 |

## 实时机械物理

采用 Three.js 与 cannon-es，以 **1/120 秒固定步长**求解。轮、轴、齿轮、浑象、浑仪内环、时牌轮、天衡、随动件、槌臂和铜钟均为动态刚体。所有可动机械网格只从刚体读取位姿。轴承使用铰链约束；齿轮使用带相位校正的角约束，由求解器分配转矩，没有电机、关键帧或指定转速。

落水粒子按重力运动，被受水壶吸收时转移质量与动量。留存在轮上的水按实际半径施加重力，降到低处后排水。天衡承受理想支承连杆传递的载荷和配重重力，偏转到阈值后才释放棘止约束；下一齿到达后重新接住。实体凸轮盘及凸起通过碰撞抬起滚轮，连杆约束带动槌臂。槌与钟用有柔度的弹簧阻尼接触力计算，接近并碰触时才触发合成钟声。

这是面向理解的**原理剖解**，并非按《新仪象法要》逐件复原：保留三十六受水壶与水重擒纵的核心关系，简化了多级联动、链传动和原台的多层报时系统，以击钟与转出时牌作代表。影片压缩了实际节律与传动比例。半透明木构、虚线力流与载重条属于解释性图示。

## 离线构建与自检

Vite 输出本地 IIFE 脚本，构建插件移除 HTML 的 module 入口标记，因此 `file://` 也能运行，无须本地服务器。CSS 随 Vite 的 IIFE 输出内联到脚本；构建只包含 HTML 与本地脚本。

`scripts/final-check.mjs` 使用工具链 Chromium 直接打开 `file://`，检查并截图各章节与手机尺寸；`preview/` 中保留多轮检查截图。`scripts/verify-browser.mjs` 检查完整播放、声音电平、离线请求和播放控制。检查脚本的浏览器路径对应本案例提供的固定工具链。
