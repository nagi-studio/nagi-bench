# DUST II — Tactical playground

一个可直接游玩的本地 5v5 第一人称射击原型。React 18 + TypeScript + three.js，无外部模型、贴图或音频文件。包含完整的 Dust2 核心路线，地图是为本原型重新搭建的程序化版本，并非原版地图的逐尺寸复刻。

```bash
npm install
npm run dev
```

打开终端显示的地址（默认 http://localhost:5173），选择阵营、装备、标准局或手枪局，点击 **DEPLOY TO DUST II**。需桌面浏览器支持 WebGL、Pointer Lock 和 Web Audio，首次点击开始后音频启动。Esc 暂停游戏并释放鼠标。无须服务端或联网。

## 操作

| 按键            | 动作                                       |
| --------------- | ------------------------------------------ |
| WASD / 鼠标     | 移动 / 转向                                |
| 空格 / 左 Shift | 跳跃 / 静步                                |
| 左键 / 右键     | 射击、挥刀 / AWP 开镜                      |
| 1 / 2 / 3、滚轮 | 主武器 / 副武器 / 刀                       |
| R               | 换弹                                       |
| 持续按 E        | T 在 A/B 点下包 3.2 秒；CT 近距离拆包 8 秒 |
| G               | 丢弃 C4；T 靠近掉落的 C4 自动拾取          |
| F               | 阵亡后接管存活的队友                       |
| Tab             | 查看战绩                                   |
| Esc / H         | 暂停 / 操作手册                            |

每局 1:55，C4 安放后 40 秒爆炸。歼灭、爆炸、拆除和超时均能结束回合，7 秒后自动开始下一局。若 T 已下包，消灭全部 T 后 CT 仍须拆除炸弹。手枪局中所有人仅持阵营默认手枪和刀，无护甲；标准局拥有 100 护甲。设置的回合类型应用于该次游玩的每一回合。

## 地图与战场

- T 出生点连通上中路、A 大入口和 B 洞入口。
- 中路经可穿越的木制中门通向 CT 出生点；下层 B 洞连接中路。
- 上中路经猫道、小道通向 A 点；A 大经长门通向 A 点。
- B 洞连接 B 点，B 点经 CT 横道连接 CT 出生点和 A 点。
- 所有边界墙、木门和箱体都有碰撞，AI 的 A\* 路网由同一个碰撞查询生成。
- 共 10 名人形角色，独立头、胸、腹、双臂和双腿。CT 蓝灰制服、T 沙色制服。AI 能感知视野内未被墙遮挡的敌人，交战、推进、回收炸弹、下包、守包和拆包。
- 小地图常驻显示完整地图、队友、任一存活队友可见的敌人以及 C4。敌人失去视线后消失。

## 武器与伤害

可选择 AK-47、M4A4、AWP 和沙鹰；默认副武器是 T 的 Glock-18 或 CT 的 USP-S，另配近战刀。数据表在 `src/game/weapons.ts`，可扩展射速、弹匣、备弹、换弹、射程、护甲穿透、后坐力、扩散与自动射击。

射线先与世界遮挡比较，再与人形的各个独立 hitbox 相交。头部为胸部的 2 倍基础伤害，腹部 1.15、手臂 0.75、腿部 0.65。护甲依穿透率减伤并损耗。AWP 胸部命中即使满甲也可一枪击杀。友军会挡住子弹但不受伤。

## 架构

| 模块                  | 职责                                                                                    |
| --------------------- | --------------------------------------------------------------------------------------- |
| `src/game/engine.ts`  | 权威游戏状态、60Hz 固定步长模拟、输入、射线命中、AI 状态机、C4 生命周期、回合和渲染协调 |
| `src/game/map.ts`     | 区域并集、共享碰撞、圆形角色移动、障碍物、A\* 寻路                                      |
| `src/game/scene.ts`   | 程序化建筑、木门、箱体、CanvasTexture 材质、角色、武器与手臂                            |
| `src/game/weapons.ts` | 可扩展武器配置与命中分区伤害计算                                                        |
| `src/game/audio.ts`   | Web Audio 振荡器与噪声合成的开火、脚步、命中、换弹、开镜、C4、击杀等音效                |
| `src/App.tsx`         | React 菜单、HUD、SVG 小地图、计分板、暂停与接管操作                                     |

引擎独立于 React 保存可变模拟状态，`requestAnimationFrame` 使用累加器驱动固定步长更新。约每 75ms 推送不可变快照到 React，HUD 不会驱动 3D 场景重新创建。组件卸载时移除输入监听器、取消动画循环并释放 WebGL / 音频资源。暂停时冻结模拟。开发模式可通过 `window.__DUST__` 查看引擎状态进行调试。

```bash
npm run build    # TypeScript 校验与生产构建
npm run preview  # 预览构建
npm test         # 路线连通性、路径碰撞、快速移动与伤害数据测试
```

原型聚焦本地对战，无联网、经济系统、买枪阶段或原版 Dust2 的所有装饰细节。AI 使用平面路径图和简化的战术规则，声音是距离衰减的程序化反馈。
