# 陨石的方向

一部 230 秒的程序化体素电影。原文被压缩为收藏室、加工、地下室验证、黄河站合影、十秒弹道及返航六个叙事段落。片尾把章北海的抉择留在道德疑问中。

## 播放

项目只使用离线预装的 Bun、Three.js、Vite、AgentBench Cinematic Player 与 Voxel Kit。

```sh
bun run dev
```

或使用已构建的 `dist/`：

```sh
bun run preview
```

点击播放解锁音频。播放器支持暂停、跳转、音量和全屏。

## 制作结构

- `src/main.js`：16 个绝对时间镜头、程序化场景/人物调度和音效 cue。
- `src/voice.js`：全部待配音内容的唯一七字段清单，直接驱动中文字幕。
- `src/assets/audio/`：从平台离线 CC0 音效库挑选的采样。
- `dist/`：标准 Vite 静态构建，可连同 `assets/` 一起部署。

真空中的开枪以画面闪光和航天服内传导的轻微碰击表现；地下室试射则叠加采样与延迟反射。
